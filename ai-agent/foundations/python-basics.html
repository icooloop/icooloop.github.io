Python 基础 ​

这一页不假设你写过 Python。我们会从运行第一行代码开始，逐步做出一个不依赖大模型、无需 API Key 的规则型客服 Agent。它虽然还不会真正“思考”，但已经具备 Agent 应用最基本的数据流：

  -> 记录消息

用这个小项目学习语法，比孤立地计算圆面积更接近后续课程。学完后，你应该能读懂普通 Python 程序，并能独立解释：数据放在哪里、函数怎样传递数据、对象怎样协作、类型标注在保护什么。

本教程验证基线是 Python 3.12.13。下面使用了 Python 3.12 可以运行的语法，但不声称它是当前最新版本。先用同一基线完成练习，能减少由版本差异造成的干扰。

2. Python 的四种运行方式 ​

同一段 Python 代码可以在不同环境中执行。它们适合不同任务。

2.1 解释器与 REPL ​

在终端输入 python 会进入 REPL（Read-Eval-Print Loop，读取、求值、打印循环）：

text
>>> 2 + 3
5
>>> "agent".upper()
'AGENT'
1
2
3
4

REPL 适合快速验证一两行表达式。退出方式：

python
exit()
1

>>> 是 REPL 提示符，不要把它复制进 .py 文件。

2.2 脚本 ​

.py 文件适合保存和重复执行。运行：

powershell
python hello_agent.py
1

Python 从文件第一行向下执行。语法错误会在执行前被发现，运行时错误则可能在执行到对应行时才出现。

2.3 模块 ​

一个 .py 文件也是一个模块。后面把代码组织成包时，推荐从项目根目录使用 -m：

powershell
python -m support_agent.cli
1

-m 的意思是“按照模块导入规则运行”，它通常比直接运行包内部的文件更不容易出现导入错误。

2.4 Jupyter Notebook ​

Notebook 按单元格执行，适合探索数据、Prompt 和模型返回值。但单元格可以不按顺序运行，变量也可能残留，所以它不适合作为生产程序的唯一载体。

方式适合不适合
REPL验证一个表达式保存完整应用
脚本小程序、自动化任务大项目全部塞进单文件
python -m运行包中的入口模块随手试一行代码
Notebook实验、数据观察、教学隐藏状态较多的生产服务

13. 综合实战：一个可运行的规则型客服 Agent ​

现在把前面的变量、容器、函数、类、Protocol、生成器和上下文管理器放进一个程序。新建 rule_agent.py：

python
from __future__ import annotations

from collections.abc import Iterator
from contextlib import contextmanager
from dataclasses import dataclass, field
from time import perf_counter
from typing import Protocol


@dataclass(frozen=True)
class Message:
    role: str
    content: str


@dataclass
class AgentState:
    messages: list[Message] = field(default_factory=list)
    called_tools: list[str] = field(default_factory=list)


class Tool(Protocol):
    name: str
    description: str

    def run(self, argument: str) -> str:
        ...


class OrderSearchTool:
    name = "search_order"
    description = "根据订单号查询物流状态"

    def __init__(self, orders: dict[str, str]) -> None:
        self.orders = orders

    def run(self, argument: str) -> str:
        return self.orders.get(argument, f"没有找到订单 {argument}")


class PolicyTool:
    name = "lookup_policy"
    description = "查询退款政策"

    def run(self, argument: str) -> str:
        if "退款" in argument:
            return "未发货订单可直接申请退款；已发货订单需先拒收或退货。"
        return "没有找到相关政策。"


@contextmanager
def measure(name: str) -> Iterator[None]:
    started = perf_counter()
    try:
        yield
    finally:
        elapsed = perf_counter() - started
        print(f"[metric] {name}={elapsed:.4f}s")


def extract_order_id(message: str) -> str | None:
    for word in message.replace("，", " ").split():
        candidate = word.strip("？?。.").upper()
        if candidate.startswith("A-") and candidate[2:].isdigit():
            return candidate
    return None


def choose_tool(message: str) -> tuple[str, str] | None:
    if "订单" in message or "物流" in message:
        order_id = extract_order_id(message)
        if order_id is None:
            return None
        return "search_order", order_id

    if "退款" in message:
        return "lookup_policy", message

    return None


def stream_text(text: str) -> Iterator[str]:
    for character in text:
        yield character


class RuleAgent:
    def __init__(self, tools: list[Tool]) -> None:
        self.tools = {tool.name: tool for tool in tools}

    def run(self, user_message: str, state: AgentState) -> str:
        cleaned = " ".join(user_message.strip().split())
        state.messages.append(Message(role="user", content=cleaned))

        decision = choose_tool(cleaned)
        if decision is None:
            if "订单" in cleaned or "物流" in cleaned:
                answer = "请提供形如 A-1001 的订单号。"
            else:
                answer = "我暂时只能查询订单和退款政策，已建议转人工。"
        else:
            tool_name, argument = decision
            tool = self.tools.get(tool_name)
            if tool is None:
                answer = f"工具 {tool_name} 不可用，已建议转人工。"
            else:
                state.called_tools.append(tool_name)
                result = tool.run(argument)
                answer = f"工具 {tool_name} 返回：{result}"

        state.messages.append(Message(role="assistant", content=answer))
        return answer


def main() -> None:
    orders = {
        "A-1001": "已发货，预计明天送达",
        "A-1002": "等待付款",
    }
    agent = RuleAgent(
        tools=[
            OrderSearchTool(orders),
            PolicyTool(),
        ]
    )
    state = AgentState()

    print("规则型客服 Agent 已启动，输入 quit 退出。")
    while True:
        user_message = input("你：")
        if user_message.strip().lower() == "quit":
            break

        with measure("agent_run"):
            answer = agent.run(user_message, state)

        print("助手：", end="")
        for chunk in stream_text(answer):
            print(chunk, end="", flush=True)
        print()

    print(f"本次会话共 {len(state.messages)} 条消息")
    print(f"调用过的工具：{state.called_tools}")


if __name__ == "__main__":
    main()
