LlamaIndex RAG ​

前面已经学习了 RAG 的通用链路和 LangChain 实现。LlamaIndex 不是另一种 RAG 原理，而是一套更专注于数据接入、索引、检索与查询编排的 Python 框架。

本章要解决三个问题：

  1. LlamaIndex 的 Document、Node、Index、Retriever 和 Query Engine 分别负责什么？
  2. 怎样从最小 RAG 逐步走到可更新、可引用、可组合的知识系统？
  3. 已经在使用 LangChain/LangGraph 时，什么场景还值得引入 LlamaIndex？

IMPORTANT

官方发布元数据已核验本页目标基线为 llama-index==0.14.23、llama-index-core==0.14.23。当前项目仍未安装 LlamaIndex、Embedding 集成包或向量数据库集成包，所以不能声称框架代码已在本地通过。标为“LlamaIndex API”的代码必须在安装目标版本后核对导入路径、参数并运行；标为“标准库离线示例”的代码不依赖 LlamaIndex，可以直接用于理解数据契约。

  -> 索引
  -> 检索

LlamaIndex 为这些阶段提供了相互配合的抽象：

RAG 阶段LlamaIndex 常见抽象作用
原始数据Document、Reader读取文本与元数据
知识单元Node / TextNode可索引、可引用的片段
数据处理Transformation、IngestionPipeline切分、提取元数据、Embedding
索引VectorStoreIndex 等组织可检索数据
检索Retriever返回相关 Node 与分数
生成Response Synthesizer根据 Node 合成答案
对外查询Query Engine组合检索与响应合成
对话Chat Engine在查询能力上加入对话上下文
复杂路由Router、SubQuestion、Workflow选择数据源或分解问题

最容易混淆的是 Index、Retriever 和 Query Engine：

text
Index      保存或组织“怎么找到数据”
Retriever 根据问题返回相关 Node
QueryEngine = Retriever + Response Synthesizer
1
2
3

Query Engine 不是向量数据库，Index 也不等于“所有数据都存进 LlamaIndex 内存”。真实向量和原文可以落在 Qdrant、pgvector、Milvus 等外部系统中，LlamaIndex 负责适配与编排。

一个合格 Node 至少应有：

  • 稳定 node_id；

Metadata 可以参与过滤、引用，也可能被拼入 Embedding 或 LLM 上下文。敏感字段不应因为“方便”而全部暴露给模型。

用于引用：source_id、title、page
用于 Embedding：通常是标题、章节等语义字段

from hashlib import sha256


def content_hash(text: str) -> str:
    normalized = " ".join(text.split())
    return sha256(normalized.encode("utf-8")).hexdigest()


def requires_reindex(
    *,
    old_hash: str | None,
    new_text: str,
) -> bool:
    return old_hash != content_hash(new_text)

def validate_nodes(nodes) -> None:
    ids: set[str] = set()
    for node in nodes:
        if node.node_id in ids:
            raise ValueError(f"duplicate node id: {node.node_id}")
        ids.add(node.node_id)

        if not node.get_content().strip():
            raise ValueError(f"blank node: {node.node_id}")

        required = {"source_id", "version", "tenant_id"}
        missing = required - set(node.metadata)
        if missing:
            raise ValueError(
                f"node {node.node_id} missing metadata: {missing}"
            )

10. Metadata Filter 与权限 ​

检索前必须按租户、角色和有效版本过滤，而不是检索后再从 Top-K 删除越权结果。

概念示例：

python
def authorize_metadata(
    metadata: dict,
    *,
    tenant_id: str,
    role: str,
) -> bool:
    return (
        metadata.get("tenant_id") == tenant_id
        and role in metadata.get("allowed_roles", [])
        and metadata.get("is_current") is True
    )

16. SubQuestion：分解跨数据源问题 ​

问题“退款政策要求多久审核，我的 A-100 是否已经超时？”包含两类数据：

text

18. LlamaIndex GraphRAG ​

LlamaIndex 可以与 Property Graph、图存储和图检索组合，但“用了图索引”不自动等于高质量 GraphRAG。仍需要：

  • 实体与关系 Schema；
  • 实体消歧；
  • 来源证据；
  • 增量更新；
  • 图遍历深度限制；

20. 一个框架无关的离线最小 Query Engine ​

下面用标准库实现 Index -> Retriever -> Synthesizer -> QueryEngine 的核心契约，当前环境可以直接运行。

python
from __future__ import annotations

from dataclasses import dataclass
import re


@dataclass(frozen=True)
class Node:
    node_id: str
    text: str
    source_id: str
    tenant_id: str


@dataclass(frozen=True)
class NodeWithScore:
    node: Node
    score: float


def terms(text: str) -> set[str]:
    ascii_words = re.findall(r"[a-zA-Z0-9]+", text.lower())
    chinese_chars = re.findall(r"[\u4e00-\u9fff]", text)
    return set(ascii_words + chinese_chars)


class InMemoryRetriever:
    def __init__(self, nodes: list[Node]) -> None:
        self.nodes = nodes

    def retrieve(
        self,
        query: str,
        *,
        tenant_id: str,
        top_k: int = 3,
    ) -> list[NodeWithScore]:
        query_terms = terms(query)
        scored: list[NodeWithScore] = []

        for node in self.nodes:
            if node.tenant_id != tenant_id:
                continue
            node_terms = terms(node.text)
            union = query_terms | node_terms
            score = (
                len(query_terms & node_terms) / len(union)
                if union
                else 0.0
            )
            if score > 0:
                scored.append(NodeWithScore(node=node, score=score))

        return sorted(
            scored,
            key=lambda item: (-item.score, item.node.node_id),
        )[:top_k]


class EvidenceSynthesizer:
    def synthesize(
        self,
        query: str,
        nodes: list[NodeWithScore],
    ) -> dict:
        if not nodes:
            return {
                "answer": "没有找到足够证据，无法确认。",
                "citations": [],
            }

        evidence = "\n".join(
            f"[{item.node.node_id}] {item.node.text}"
            for item in nodes
        )
        return {
            "answer": f"待模型根据以下证据回答：\n{evidence}",
            "citations": [item.node.node_id for item in nodes],
        }


class QueryEngine:
    def __init__(
        self,
        retriever: InMemoryRetriever,
        synthesizer: EvidenceSynthesizer,
    ) -> None:
        self.retriever = retriever
        self.synthesizer = synthesizer

    def query(self, text: str, *, tenant_id: str) -> dict:
        nodes = self.retriever.retrieve(
            text,
            tenant_id=tenant_id,
            top_k=3,
        )
        return self.synthesizer.synthesize(text, nodes)


nodes = [
    Node(
        node_id="refund-policy#review",
        text="退款审核通常需要三个工作日。",
        source_id="refund-policy",
        tenant_id="acme",
    ),
    Node(
        node_id="other-tenant#secret",
        text="退款审核立即完成。",
        source_id="private-policy",
        tenant_id="other",
    ),
]

engine = QueryEngine(
    retriever=InMemoryRetriever(nodes),
    synthesizer=EvidenceSynthesizer(),
)

print(engine.query("退款审核需要几天？", tenant_id="acme"))

21. 常见失败路径 ​

21.1 Reader 返回了数据，但内容是乱码 ​

不要继续 Embedding。先建立解析质量检查、OCR 路由和人工抽样。

21.2 Node ID 每次运行都变化 ​

无法可靠更新、删除、去重和引用。使用 source_id + version + position/content_hash 生成稳定 ID。

21.3 更换 Embedding 后复用旧索引 ​

旧向量与新查询向量不在同一空间。必须建立新索引版本并重新 Embedding。

21.4 Query Engine 有答案，但 Retriever 没有正确证据 ​

这是幻觉，不是检索成功。最终答案不能掩盖 Retriever 失败。

21.5 Metadata Filter 写了但没有下推 ​

检查具体 Vector Store 集成生成的查询和服务端结果，不能只看 Python 对象配置。

21.6 全局 Settings 被测试污染 ​

测试 A 修改全局 Embedding，测试 B 意外复用。关键组件优先显式注入，并在测试中隔离全局状态。
