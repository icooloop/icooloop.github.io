Deep Agents ​

Deep Agents 是构建长任务 Agent 的 Harness：它在 LangChain/LangGraph 之上组合规划、文件系统式上下文卸载、Subagent、摘要、长期记忆和 Backend。它不是一个更“聪明”的模型，也不会自动解决权限、幂等、评测和持久化。

可以把它理解为：

text
LangChain Model/Tools
  + LangGraph State/Runtime/Persistence
  + Planning Middleware
  + Filesystem Middleware + Backend
  + SubAgent Middleware
  + Memory/Skills/Summarization/Rubric Middleware
  = Deep Agent Harness

IMPORTANT

本页以 deepagents==0.6.12 为边界。该包现已安装：公开签名、默认工具、Backend 和 Middleware 已核对，并使用自定义离线 BaseChatModel 跑通 create_deep_agent() 与 StateBackend 的 write_file -> read_file 工具回环。真实供应商模型、Skills、Memory、自定义 Subagent、Shell/Sandbox、CLI 与 ACP 尚未运行。后面的标准库示例用于解释安全契约，不冒充 Deep Agents 实现。

1. 为什么需要 Agent Harness ​

短任务可以用一个 Prompt + Tools 完成。长任务会出现：

  • 计划在多次模型调用间丢失；
  • 中间资料挤满消息上下文；
  • 一个 Agent 同时拥有太多领域工具；
  • 子任务需要隔离上下文；
  • 产物需要文件式组织；
  • 工作跨线程，需要长期记忆；
  • 用户需要在危险操作前审批；
  • 失败后需要从 checkpoint 恢复。

Harness 提供约定和中间件，减少每个项目重复实现基础设施。它仍需应用定义任务边界、Backend、安全策略和成功标准。

3.1 已验证的真实 API 文件回环 ​

下面使用实现 bind_tools() 的离线模型，让 Deep Agent 依次调用 write_file、read_file 并结束。它直接运行官方 create_deep_agent()，不是 Harness 模拟：

python
from __future__ import annotations

from collections.abc import Sequence
from typing import Any

from deepagents import create_deep_agent
from langchain_core.language_models.chat_models import BaseChatModel
from langchain_core.messages import AIMessage, BaseMessage, ToolMessage
from langchain_core.outputs import ChatGeneration, ChatResult
from langchain_core.tools import BaseTool
from pydantic import Field


class ScriptedDeepAgentModel(BaseChatModel):
    responses: list[AIMessage]
    index: int = 0
    bound_tool_names: list[str] = Field(default_factory=list)

    @property
    def _llm_type(self) -> str:
        return "scripted-deep-agent-model"

    def _generate(
        self,
        messages: list[BaseMessage],
        stop: list[str] | None = None,
        run_manager: Any = None,
        **kwargs: Any,
    ) -> ChatResult:
        response = self.responses[self.index]
        self.index += 1
        return ChatResult(
            generations=[ChatGeneration(message=response)]
        )

    def bind_tools(
        self,
        tools: Sequence[dict[str, Any] | type | BaseTool],
        *,
        tool_choice: str | None = None,
        **kwargs: Any,
    ) -> "ScriptedDeepAgentModel":
        self.bound_tool_names = [
            item.name if isinstance(item, BaseTool) else str(item)
            for item in tools
        ]
        return self


model = ScriptedDeepAgentModel(
    responses=[
        AIMessage(
            content="",
            tool_calls=[
                {
                    "name": "write_file",
                    "args": {
                        "file_path": "/notes.txt",
                        "content": "hello",
                    },
                    "id": "write-1",
                    "type": "tool_call",
                }
            ],
        ),
        AIMessage(
            content="",
            tool_calls=[
                {
                    "name": "read_file",
                    "args": {"file_path": "/notes.txt"},
                    "id": "read-1",
                    "type": "tool_call",
                }
            ],
        ),
        AIMessage(content="done"),
    ]
)

agent = create_deep_agent(model=model)
result = agent.invoke(
    {"messages": [{"role": "user", "content": "write and read"}]}
)

tool_messages = [
    message
    for message in result["messages"]
    if isinstance(message, ToolMessage)
]

assert {"write_todos", "read_file", "write_file", "task"}.issubset(
    model.bound_tool_names
)
assert [message.name for message in tool_messages] == [
    "write_file",
    "read_file",
]
assert "hello" in tool_messages[1].content
assert result["files"]["/notes.txt"]["content"] == "hello"
assert result["messages"][-1].content == "done"

print(result.keys())
print([message.name for message in tool_messages])
print(result["files"]["/notes.txt"]["content"])

4. 默认能力不是默认授权 ​

0.6.12 的默认工具族包括：

能力工具
规划write_todos
文件浏览ls、glob、grep
文件读写read_file、write_file、edit_file
执行execute 属于工具族/图 ToolNode；仅 SandboxBackendProtocol Backend 会向模型暴露
子任务默认有 task，可调用内置 general-purpose Subagent；也可配置自定义 Subagent

“默认可用”描述 Harness 组装行为，不等于部署者应该开放所有能力。特别是 execute、写文件、网络和持久记忆需要工具/Backend 层强制权限。

execute 存在于编译图的工具族/ToolNode，不代表模型总能选择它。Filesystem Middleware 会根据运行时解析出的 Backend 动态过滤工具；默认 StateBackend 不实现 SandboxBackendProtocol，因此不会把 execute 绑定给模型。只有明确配置支持该协议的沙箱 Backend，并设置权限、资源限制和中断策略后，模型才会看到执行工具。

模型 Prompt 中写“不要访问其他目录”不是沙箱。必须通过虚拟路径、根目录限制、系统调用隔离、网络策略和人工中断落实。

5. Planning 与 write_todos ​

Todo 是外部化的工作计划：

text
pending -> in_progress -> completed / failed / blocked
1

它的价值：

  • 让长任务当前目标可观察；
  • 便于检测没有进展；
  • 为恢复和用户界面提供状态；
  • 将任务分解与聊天文本分离。

Todo 不是正确性证明。模型可能：

  • 写出无法执行的任务；
  • 同时把多个任务标成 in_progress；
  • 完成后忘记更新；
  • 反复改写计划但没有产物；
  • 用 Todo 绕过工具权限。

应用应检查：

python
from dataclasses import dataclass
from typing import Literal


@dataclass(frozen=True)
class Todo:
    todo_id: str
    description: str
    status: Literal["pending", "in_progress", "completed", "failed"]
    artifact_path: str | None = None


def validate_todos(todos: list[Todo], *, max_items: int) -> None:
    if not 1 <= len(todos) <= max_items:
        raise ValueError("todo count outside budget")
    if len({item.todo_id for item in todos}) != len(todos):
        raise ValueError("todo ids must be unique")
    if sum(item.status == "in_progress" for item in todos) > 1:
        raise ValueError("only one todo may be in progress")

6.1 路径边界 ​

  • 规范化路径后确认仍在允许根目录；
  • 拒绝 ..、绝对路径、设备路径和符号链接逃逸；
  • 每个任务独立 workspace；
  • 文件大小、数量和总字节有上限；
  • 读写与执行权限分离；
  • 文件内容仍是不可信数据。

6.2 上下文卸载不是长期记忆 ​

State Backend 中的文件可能只随当前 Agent State 存活；Filesystem Backend 的文件可能落到宿主机；Store Backend 才面向跨线程数据。选择 Backend 决定持久性和隔离，不能仅凭路径 /memories/... 推断。

7. Backend ​

0.6.12 公开 Backend 包括：

Backend定位关键边界
State文件存入 Agent State受 checkpoint 生命周期和 State 大小影响
Store文件/记忆映射到 LangGraph Store需要 Namespace、租户和删除策略
Filesystem访问文件系统根目录、符号链接、宿主权限
LocalShell本地文件与命令执行高风险，只能在强隔离环境使用
Composite按路径路由多个 Backend路由顺序、跨 Backend 移动语义
ContextHub连接上下文资源外部服务权限与版本相关

9. 自动摘要 ​

长上下文超过阈值时，Summarization Middleware 可以压缩较早消息。摘要应保留：

  • 当前目标和未完成 Todo；
  • 已确认的约束；
  • 关键证据 ID 和产物路径；
  • 错误与审批状态；
  • 不可重复的副作用结果。

摘要会丢信息或引入错误。金额、权限、审批和工具结果应保留结构化 State；重要来源回到文件/Artifact，不只留摘要文本。

评测摘要前后：任务成功率、遗漏约束率、错误引用率、token 和延迟。不能只看压缩率。

11. Long-term Memory ​

memory 和 Store 能让 Harness 跨线程读取偏好、经验或项目资料。长期记忆必须按 (tenant, user/project, category) 隔离，并带：

text
source, consent, version, created_at, expires_at,
sensitivity, supersedes, deletion_status
1
2

记忆写入不应由模型一句话直接决定。Memory Middleware 负责能力，应用策略负责是否允许。

Skills 与 Memory 不同：

  • Memory 是运行中产生、可能被更正和删除的数据；
  • Skill 是受审查、版本控制的程序知识或操作说明；
  • 用户文本不能自动升级成 Skill；
  • Skill 更新应走代码审查或受控发布。

完整记忆策略见 LangChain 与 LangGraph 记忆管理。

12. Skills 与 Rubric ​

Skills 为特定任务提供可加载知识和流程，减少每次都把所有说明放进 System Prompt。应根据任务选择最小 Skill 集，记录版本和来源。

Rubric Middleware 可以把验收标准显式化，例如研究报告必须：

text
至少 3 个授权来源
每个事实有引用
包含限制与不确定性
无跨租户内容

13. Permissions、Sandbox 与人在回路 ​

permissions、Backend 和 interrupt_on 共同构成执行边界。高风险操作：

  • Shell/execute；
  • 写宿主文件；
  • 网络访问；
  • 安装依赖；
  • 读取密钥；
  • 删除/覆盖文件；
  • 提交代码或外部消息；
  • 写长期记忆。

策略示例：

/memories/** -> tenant-scoped policy

14. 完整可运行离线 Harness 基线 ​

下面用标准库实现一个最小契约：Todo、虚拟文件系统、两个 Subagent、长期记忆命名空间、Artifact 和步骤预算。它用于理解 Harness，不是 Deep Agents 的替代包。

python
from __future__ import annotations

from dataclasses import dataclass, replace
from hashlib import sha256
from typing import Callable, Literal


@dataclass(frozen=True)
class Todo:
    todo_id: str
    description: str
    status: Literal["pending", "in_progress", "completed", "failed"]
    artifact_path: str | None = None


@dataclass(frozen=True)
class Artifact:
    path: str
    content_hash: str
    created_by: str
    source_ids: tuple[str, ...]


class VirtualWorkspace:
    def __init__(self, *, max_bytes: int = 10_000) -> None:
        self._files: dict[str, str] = {}
        self._max_bytes = max_bytes

    @staticmethod
    def _validate(path: str) -> None:
        if not path.startswith("/workspace/"):
            raise PermissionError("path outside workspace")
        if ".." in path.split("/"):
            raise PermissionError("path traversal rejected")

    def write(self, path: str, content: str) -> Artifact:
        self._validate(path)
        future = dict(self._files)
        future[path] = content
        total = sum(len(value.encode("utf-8")) for value in future.values())
        if total > self._max_bytes:
            raise RuntimeError("workspace quota exceeded")
        self._files = future
        return Artifact(
            path=path,
            content_hash=sha256(content.encode("utf-8")).hexdigest(),
            created_by="harness",
            source_ids=(),
        )

    def read(self, path: str) -> str:
        self._validate(path)
        return self._files[path]


class ScopedMemory:
    def __init__(self) -> None:
        self._items: dict[tuple[str, str, str], str] = {}

    def put(self, tenant: str, project: str, key: str, value: str) -> None:
        self._items[(tenant, project, key)] = value

    def get(self, tenant: str, project: str, key: str) -> str | None:
        return self._items.get((tenant, project, key))


Subagent = Callable[[str, VirtualWorkspace], Artifact]


def researcher(task: str, workspace: VirtualWorkspace) -> Artifact:
    content = (
        "Evidence: refund review takes three business days.\n"
        "Source: policy:refund@2026-07\n"
        f"Task: {task}\n"
    )
    artifact = workspace.write("/workspace/evidence.md", content)
    return replace(
        artifact,
        created_by="researcher",
        source_ids=("policy:refund@2026-07",),
    )


def writer(task: str, workspace: VirtualWorkspace) -> Artifact:
    evidence = workspace.read("/workspace/evidence.md")
    content = f"Report\n\n{evidence}\nRequested: {task}\n"
    artifact = workspace.write("/workspace/report.md", content)
    return replace(
        artifact,
        created_by="writer",
        source_ids=("policy:refund@2026-07",),
    )


class OfflineHarness:
    def __init__(self, *, max_steps: int = 6) -> None:
        self.workspace = VirtualWorkspace()
        self.memory = ScopedMemory()
        self.max_steps = max_steps
        self.subagents: dict[str, Subagent] = {
            "researcher": researcher,
            "writer": writer,
        }

    def run(self, request: str, *, tenant: str, project: str) -> list[Todo]:
        todos = [
            Todo("research", "Collect policy evidence", "pending"),
            Todo("write", "Write cited report", "pending"),
        ]
        steps = 0

        for index, (todo, agent_name) in enumerate(
            zip(todos, ("researcher", "writer"), strict=True)
        ):
            steps += 1
            if steps > self.max_steps:
                raise RuntimeError("step budget exhausted")

            todos[index] = replace(todo, status="in_progress")
            artifact = self.subagents[agent_name](request, self.workspace)
            todos[index] = replace(
                todos[index],
                status="completed",
                artifact_path=artifact.path,
            )

        self.memory.put(
            tenant,
            project,
            "last_report",
            todos[-1].artifact_path or "",
        )
        return todos

15. Checkpointer 与长任务恢复 ​

create_deep_agent() 接收 checkpointer 和 store。二者职责：

text
checkpointer -> 当前 thread 的消息、Todo、文件状态和中断位置
store        -> 跨 thread 的长期记忆/持久文件
1
2

使用持久 Checkpointer 还不保证外部命令可重放。execute、网络写和提交动作需要幂等标识、执行记录和未知结果查询。

升级 Harness 时要测试旧 checkpoint 的 State Schema 和 Middleware 状态能否读取。无法兼容时迁移或让旧线程使用旧 Worker，不要直接用新代码恢复所有历史任务。

16. CLI 与 ACP ​

Deep Agents 主包 deepagents==0.6.12 的 wheel 本身不包含 CLI 命令。CLI 与 ACP（Agent Client Protocol）是两个独立候选包：

text
deepagents-cli==0.2.2
deepagents-acp==0.0.9
1
2

两者均未安装。CLI 面向交互式运行，ACP 用于把 Agent 连接到兼容客户端；不要把它们描述成主包导入后自动存在的模块。具体命令、协议消息和能力必须分别按上述版本验证，本页不提供未经运行的命令。

使用这些表面前仍需定义：

  • 认证和会话身份；
  • workspace/Backend 生命周期；
  • Tool 与网络权限；
  • 中断、取消和重连；
  • Artifact 下载与敏感数据；
  • Trace、审计和保留；
  • 多租户并发与配额。

协议可连接客户端，不会自动建立沙箱。

17. 失败路径 ​

Todo 很完整但没有产物 ​

模型进行“计划表演”。以 Artifact、测试和 Rubric 作为完成条件，并检测 Todo 长时间不减少。

上下文卸载后找不到关键信息 ​

路径不稳定、摘要未保留 Artifact ID 或 Backend 生命周期不匹配。建立 Manifest，并测试恢复后可读取。

Subagent 泄露父 Agent 数据 ​

传入了完整消息或共享 Backend。使用 Task Envelope、路径路由、工具白名单和私有 State。

/workspace 看似隔离却能读宿主文件 ​

Filesystem/LocalShell Backend 配置错误、符号链接逃逸或执行工具绕过。必须用实际沙箱攻击测试，不能只检查字符串路径。

长期记忆污染 ​

外部文档或模型推断被自动保存。写入前执行来源、同意、敏感性、冲突和版本策略。

自动摘要丢失审批结果 ​

关键状态只在消息文本中。把审批、金额、副作用回执保存为结构化 State，摘要只用于上下文。

依赖可装但主项目回归 ​

Deep Agents 引入额外供应商集成和传递依赖。使用隔离环境审计并运行全套测试，再决定是否合并锁文件。

18. 练习 ​

练习一：Todo 验收 ​

为离线 Harness 增加失败状态和 Artifact Rubric。没有来源 ID 的报告不能标 completed。

练习二：Composite Backend 设计 ​

设计 /workspace、/memories 和 /skills 三条路由，写清持久性、读写权限、租户 Namespace、配额和删除。

练习三：Subagent 隔离 ​

增加代码分析 Subagent，只允许读取 /workspace/src，不能读取研究证据或长期记忆。

练习四：摘要回归 ​

准备 20 个长任务，在摘要前后比较约束保留、来源、Todo 和任务成功率。

练习五：Sandbox 红队 ​

测试路径穿越、符号链接、命令注入、网络外传、Fork Bomb、超大输出和超时。任何 Prompt 规则都不能作为唯一防线。

练习六：隔离环境复验 ​

在干净隔离环境复验 deepagents==0.6.12，核对默认工具、Backend、Middleware 和签名，记录依赖树并重跑文件回环；不得用现有环境的偶然传递依赖掩盖缺包。
