Interrupt 与人在回路 ​

Agent 可以建议退款、发送邮件或修改数据，但不应自动执行所有高风险操作。Human-in-the-loop（HITL）把人放在决策边界：工作流准备好完整草稿后暂停，由有权限的人批准、修改、拒绝或补充信息，再从同一线程继续。

LangGraph 的核心流程：

text
运行到审批节点
  -> interrupt(payload)
  -> Checkpointer 保存线程状态
  -> API 把审批载荷交给审核人
  -> 审核服务验证身份与决定
  -> Command(resume=decision)
  -> 同一 thread_id 恢复
  -> 校验决定绑定的草稿版本
  -> 执行或结束

1. 哪些操作需要人在回路 ​

常见高风险边界：

  • 资金：支付、退款、额度调整；
  • 通信：向外部客户发邮件、公开发布；
  • 数据：删除、批量修改、导出敏感数据；
  • 权限：添加管理员、扩大工具范围；
  • 法律/医疗：高影响建议或正式结论；
  • 不可逆基础设施操作；
  • Agent 证据冲突或置信不足。

不应该把所有操作都审批，否则系统变成昂贵表单。可按风险分层：

风险处理
只读、低敏感自动执行并审计
可逆、低金额策略允许时自动执行
高金额/外部副作用强制人工审批
越权/证据冲突拒绝或升级专人

4. 审批载荷必须完整绑定草稿 ​

只发送：

json
{"question": "同意退款吗？"}
1

审核人不知道同意了什么。载荷至少包含：

  • 操作类型；
  • 租户与业务资源 ID；
  • 金额和关键参数；
  • 草稿/资源版本；
  • 幂等键或操作 ID；
  • 证据与原因；
  • 风险说明；
  • 允许的决策；
  • Schema Version；
  • 可安全展示的预览。

绝不能把 API 密钥、内部凭证或无关 PII 放进 Payload。

5. 定义严格的草稿与决定 ​

使用分为单位避免 JSON/Decimal 转换歧义：

python
from typing import Literal

from pydantic import BaseModel, ConfigDict, Field, model_validator


class RefundDraft(BaseModel):
    model_config = ConfigDict(extra="forbid", strict=True, frozen=True)

    tenant: str = Field(pattern=r"^[a-z][a-z0-9_-]{1,31}$")
    workflow_id: str = Field(min_length=8, max_length=80)
    order_id: str = Field(pattern=r"^[A-Z]\d{4}$")
    amount_cents: int = Field(gt=0, le=10_000_000)
    resource_version: int = Field(ge=1)
    idempotency_key: str = Field(min_length=8, max_length=120)
    schema_version: Literal[1] = 1


class ReviewDecision(BaseModel):
    model_config = ConfigDict(extra="forbid", strict=True, frozen=True)

    action: Literal["approve", "edit", "reject"]
    reviewer: str = Field(min_length=3, max_length=64)
    tenant: str
    draft_version: int = Field(ge=1)
    modified_amount_cents: int | None = Field(
        default=None,
        gt=0,
        le=10_000_000,
    )
    reason: str = Field(min_length=1, max_length=500)

    @model_validator(mode="after")
    def validate_edit(self) -> "ReviewDecision":
        if self.action == "edit" and self.modified_amount_cents is None:
            raise ValueError("edit requires modified_amount_cents")
        if self.action != "edit" and self.modified_amount_cents is not None:
            raise ValueError("only edit may set modified_amount_cents")
        return self

7. 一个完整可运行的退款审批图 ​

python
from __future__ import annotations

from typing import Any, Literal, TypedDict

from langgraph.checkpoint.memory import InMemorySaver
from langgraph.graph import END, START, StateGraph
from langgraph.types import Command, interrupt
from pydantic import BaseModel, ConfigDict, Field, model_validator


class RefundDraft(BaseModel):
    model_config = ConfigDict(extra="forbid", strict=True, frozen=True)

    tenant: str = Field(pattern=r"^[a-z][a-z0-9_-]{1,31}$")
    workflow_id: str = Field(min_length=8, max_length=80)
    order_id: str = Field(pattern=r"^[A-Z]\d{4}$")
    amount_cents: int = Field(gt=0, le=10_000_000)
    resource_version: int = Field(ge=1)
    idempotency_key: str = Field(min_length=8, max_length=120)
    schema_version: Literal[1] = 1


class ReviewDecision(BaseModel):
    model_config = ConfigDict(extra="forbid", strict=True, frozen=True)

    action: Literal["approve", "edit", "reject"]
    reviewer: str = Field(min_length=3, max_length=64)
    tenant: str
    draft_version: int = Field(ge=1)
    modified_amount_cents: int | None = Field(default=None, gt=0)
    reason: str = Field(min_length=1, max_length=500)

    @model_validator(mode="after")
    def validate_edit(self) -> "ReviewDecision":
        if self.action == "edit" and self.modified_amount_cents is None:
            raise ValueError("edit requires modified amount")
        if self.action != "edit" and self.modified_amount_cents is not None:
            raise ValueError("only edit may set modified amount")
        return self


class ApprovalState(TypedDict, total=False):
    tenant: str
    workflow_id: str
    order_id: str
    amount_cents: int
    resource_version: int
    draft: dict[str, Any]
    decision: dict[str, Any]
    receipt: dict[str, Any]
    status: str
    error_code: str
    trace: list[str]


class FakeRefundService:
    """教学替代：用幂等键模拟业务服务端去重。"""

    def __init__(self) -> None:
        self.receipts: dict[str, dict[str, Any]] = {}
        self.fingerprints: dict[str, tuple[Any, ...]] = {}
        self.commit_count = 0

    def submit(self, draft: RefundDraft) -> dict[str, Any]:
        fingerprint = (
            draft.tenant,
            draft.order_id,
            draft.amount_cents,
            draft.resource_version,
        )
        existing = self.receipts.get(draft.idempotency_key)
        if existing is not None:
            if self.fingerprints[draft.idempotency_key] != fingerprint:
                raise ValueError(
                    "idempotency key reused for different operation"
                )
            return existing

        self.commit_count += 1
        receipt = {
            "refund_id": f"RF-{self.commit_count:04d}",
            "order_id": draft.order_id,
            "amount_cents": draft.amount_cents,
            "idempotency_key": draft.idempotency_key,
        }
        self.fingerprints[draft.idempotency_key] = fingerprint
        self.receipts[draft.idempotency_key] = receipt
        return receipt


refund_service = FakeRefundService()


def create_draft(state: ApprovalState) -> ApprovalState:
    required = ("tenant", "workflow_id", "order_id", "amount_cents")
    missing = [key for key in required if key not in state]
    if missing:
        raise ValueError(f"missing initial fields: {missing}")

    version = state.get("resource_version", 1)
    draft = RefundDraft(
        tenant=state["tenant"],
        workflow_id=state["workflow_id"],
        order_id=state["order_id"],
        amount_cents=state["amount_cents"],
        resource_version=version,
        idempotency_key=f"refund:{state['workflow_id']}:v{version}",
        schema_version=1,
    )
    return {
        "draft": draft.model_dump(mode="python"),
        "status": "drafted",
        "trace": [*state.get("trace", []), "create_draft"],
    }


def request_approval(state: ApprovalState) -> ApprovalState:
    draft = RefundDraft.model_validate(state["draft"])

    raw: Any = interrupt(
        {
            "kind": "refund_approval",
            "draft": draft.model_dump(mode="json"),
            "allowed_actions": ["approve", "edit", "reject"],
            "risk": "This operation creates a real refund.",
            "decision_schema_version": 1,
        }
    )

    decision = ReviewDecision.model_validate(raw)

    if decision.tenant != draft.tenant:
        return {
            "decision": decision.model_dump(mode="python"),
            "status": "rejected",
            "error_code": "TENANT_MISMATCH",
            "trace": [*state["trace"], "reject:tenant"],
        }
    if decision.draft_version != draft.resource_version:
        return {
            "decision": decision.model_dump(mode="python"),
            "status": "rejected",
            "error_code": "DRAFT_VERSION_MISMATCH",
            "trace": [*state["trace"], "reject:version"],
        }

    status = {
        "approve": "approved",
        "edit": "edit_requested",
        "reject": "rejected",
    }[decision.action]
    return {
        "decision": decision.model_dump(mode="python"),
        "status": status,
        "error_code": "REVIEW_REJECTED" if status == "rejected" else "",
        "trace": [*state["trace"], f"decision:{decision.action}"],
    }


def apply_edit(state: ApprovalState) -> ApprovalState:
    old = RefundDraft.model_validate(state["draft"])
    decision = ReviewDecision.model_validate(state["decision"])
    new_version = old.resource_version + 1
    edited = old.model_copy(
        update={
            "amount_cents": decision.modified_amount_cents,
            "resource_version": new_version,
            "idempotency_key": (
                f"refund:{old.workflow_id}:v{new_version}"
            ),
        }
    )
    return {
        "draft": edited.model_dump(mode="python"),
        "resource_version": new_version,
        "amount_cents": edited.amount_cents,
        "status": "waiting_review",
        "trace": [*state["trace"], "apply_edit"],
    }


def commit_refund(state: ApprovalState) -> ApprovalState:
    draft = RefundDraft.model_validate(state["draft"])
    receipt = refund_service.submit(draft)
    return {
        "receipt": receipt,
        "status": "completed",
        "trace": [*state["trace"], "commit_refund"],
    }


def route_decision(
    state: ApprovalState,
) -> Literal["commit", "edit", "stop"]:
    return {
        "approved": "commit",
        "edit_requested": "edit",
        "rejected": "stop",
    }[state["status"]]


builder = StateGraph(ApprovalState)
builder.add_node("create_draft", create_draft)
builder.add_node("request_approval", request_approval)
builder.add_node("apply_edit", apply_edit)
builder.add_node("commit_refund", commit_refund)
builder.add_edge(START, "create_draft")
builder.add_edge("create_draft", "request_approval")
builder.add_conditional_edges(
    "request_approval",
    route_decision,
    {
        "commit": "commit_refund",
        "edit": "apply_edit",
        "stop": END,
    },
)
builder.add_edge("apply_edit", "request_approval")
builder.add_edge("commit_refund", END)

graph = builder.compile(checkpointer=InMemorySaver())


def decision(
    action: Literal["approve", "edit", "reject"],
    *,
    version: int,
    modified_amount_cents: int | None = None,
) -> dict[str, Any]:
    return ReviewDecision(
        action=action,
        reviewer="reviewer-7",
        tenant="acme",
        draft_version=version,
        modified_amount_cents=modified_amount_cents,
        reason="checked against policy",
    ).model_dump(mode="python")


config = {
    "configurable": {
        "thread_id": "tenant-acme:refund:workflow-0007",
    }
}

paused = graph.invoke(
    {
        "tenant": "acme",
        "workflow_id": "workflow-0007",
        "order_id": "A1024",
        "amount_cents": 2500,
        "resource_version": 3,
        "trace": [],
    },
    config,
)
assert paused["__interrupt__"][0].value["draft"]["resource_version"] == 3

# 审核人先把金额改为 20 元；图应用编辑后再次中断。
paused_again = graph.invoke(
    Command(
        resume=decision(
            "edit",
            version=3,
            modified_amount_cents=2000,
        )
    ),
    config,
)
assert paused_again["__interrupt__"][0].value["draft"]["resource_version"] == 4
assert paused_again["__interrupt__"][0].value["draft"]["amount_cents"] == 2000

# 第二次审批必须绑定编辑后的版本 4。
completed = graph.invoke(
    Command(resume=decision("approve", version=4)),
    config,
)
assert completed["status"] == "completed"
assert completed["receipt"]["amount_cents"] == 2000
assert refund_service.commit_count == 1

# 完成后重复 resume 不会产生第二次退款；业务服务也按幂等键去重。
same = graph.invoke(
    Command(resume=decision("approve", version=4)),
    config,
)
assert same["receipt"] == completed["receipt"]
assert refund_service.commit_count == 1

9. Interrupt 节点的重放语义 ​

恢复时，包含 interrupt() 的节点会从开头重新执行，直到同一个中断位置取得 Resume 值。因此：

python
def unsafe_node(state):
    send_email("approval started")  # 恢复时可能再次执行
    decision = interrupt({...})
    return {"decision": decision}

应改为：

python
def prepare_notification(state):
    # 独立节点；仍需幂等
    return {"notification_id": ensure_notification_once(state)}


def approval_node(state):
    # interrupt 之前只做确定性、无副作用的计算
    decision = interrupt(build_payload(state))
    return {"decision": decision}

  • interrupt() 之前不要做非幂等副作用；
  • 中断调用数量和顺序应保持稳定；

  • Payload 必须可序列化；

def build_authenticated_decision(
    request_body: dict,
    *,
    session,
    expected_tenant: str,
) -> ReviewDecision:
    if "refund:approve" not in session.permissions:
        raise PermissionError("review permission required")
    if session.tenant_id != expected_tenant:

    return ReviewDecision.model_validate(

            **request_body,
            "reviewer": session.user_id,
            "tenant": session.tenant_id,

12. 版本绑定与 TOCTOU ​

审批人看到草稿后，订单可能变化。批准必须绑定：

  • Draft Version；
  • Order/Resource Version；
  • Amount；
  • Tenant；

13. 幂等键与重复 Resume ​

幂等键必须由服务端稳定生成，并绑定操作指纹：

text
key = refund:{workflow_id}:v{draft_version}
fingerprint = tenant + order + amount + resource_version
1
2

业务服务规则：

text
同 Key + 同 Fingerprint -> 返回第一次 Receipt
同 Key + 不同 Fingerprint -> 拒绝冲突
不同 Key               -> 新操作
1
2
3

仅在 LangGraph State 中记录 committed=True 不够。Worker 可能在外部服务成功后、Checkpoint 写入前崩溃，恢复时仍会再次调用。

14. 审批超时、升级与撤销 ​

interrupt() 负责暂停，不自动发送提醒或计算 SLA。外部调度系统应管理：

text
pending approval
  -> 24h reminder
  -> 48h escalation
  -> 72h expire/reject
1
2
3
4

超时任务本身需要幂等，并在 Resume 前检查线程仍在等待相同 Draft Version。

撤销申请时不能只删除前端待办。应写入结构化 Cancel Decision 或业务状态，让后续过期的 Approve 被拒绝。

15. 审计日志 ​

至少记录：

  • Workflow/Thread/Checkpoint ID；
  • Draft ID 与 Version；
  • Tenant 与业务资源 ID；
  • 审批载荷哈希；
  • 审核人认证主体与角色；
  • 决定、原因和时间；
  • 修改前后差异；
  • Resume 请求 ID；
  • 外部 Receipt；
  • 重复/冲突结果。

审计日志与可修改的 Agent State 分开保存，并遵守敏感数据最小化和保留策略。

16. LangChain HITL Middleware 与 LangGraph Interrupt ​

能力LangChain HITL Middleware直接 LangGraph Interrupt
接入速度工具审批配置简单需要显式节点和 State
适合create_agent 中拦截高风险 Tool复杂业务审批流程
编辑/多阶段审批可配置工具决策可完全自定义
State/路由Agent 运行时管理业务字段和路由显式
版本绑定仍需业务实现可在 State/节点中严格实现

简单“某工具执行前确认”可使用 Middleware；退款多阶段编辑、SLA、补偿和审计更适合显式 LangGraph。

17. 常见失败路径 ​

17.1 恢复错 Thread ​

拒绝未知 Thread，不允许仅凭 Resume Body 重建操作。

17.2 审批了旧版本 ​

比较 draft_version/resource_version，失配后重新生成草稿。

17.3 Resume 值类型错误 ​

使用严格 Pydantic Schema；不要把 "false" 当成布尔 False。

17.4 Interrupt 前发送了邮件 ​

节点恢复会重放。移动副作用到独立幂等节点或 Task。

17.5 重复批准产生重复退款 ​

业务服务端用 Idempotency Key + Fingerprint 去重。

17.6 无权限用户审批 ​

Reviewer 和 Tenant 来自认证 Session，并在 API、Workflow、业务服务三层检查。

17.7 Checkpointer 进程重启后丢失 ​

InMemorySaver 从未承诺持久化。改用验证过的持久后端并做恢复演练。

20. 本章验收标准 ​

完成本章后，你应该能够：

  • 使用 interrupt() 暂停图并读取 Payload；
  • 使用同一 Thread 和 Command(resume=...) 恢复；
  • 设计 Approve、Edit、Reject 和补充信息路由；
  • 使用严格 Schema 校验 Resume 值；
  • 将审批绑定到 Tenant、Draft 和 Resource Version；
  • 解释 Interrupt 节点为什么会从头重放；
  • 避免在 Interrupt 前执行非幂等副作用；
  • 在业务服务侧实现 Idempotency Key + Fingerprint；
  • 设计审批权限、超时、撤销和审计；
  • 判断何时使用 LangChain HITL Middleware 或显式 LangGraph。

如果审批只是 interrupt(True/False)，没有草稿版本、身份校验和幂等，就还不能用于真实业务。
