工作流评测与生产 ​

工作流最终回复正确，路径仍可能不安全：它可能调用了禁止工具、重复退款、跳过审批、在恢复后执行两次副作用，或依赖一个无法在线上复现的并发顺序。

因此要同时评测：

text
Node -> State Transition -> Route/Path -> Trace -> Terminal State
  + Interrupt/Resume
  + Retry/Idempotency
  + Parallel Reducer
  + Latency/Throughput/Cost

IMPORTANT

本页完整基线按 langgraph==1.2.9 使用 InMemorySaver、interrupt() 和 Command(resume=...) 离线运行。内存 Saver 不证明进程重启可恢复；生产 Checkpointer、真实 Worker、外部工具和模型集成需要独立故障测试。

1. 工作流测试的六层 ​

层次测什么典型断言
纯函数/Node单步转换输入不变、输出字段正确
路由条件选择高风险请求进入审批
StateReducer 与不变量状态只能合法转换
Path节点序列不调用禁止节点、步数有限
恢复Checkpoint/Interrupt恢复位置正确、副作用一次
端到端业务结果与 SLO成功、延迟、成本、引用、审计

不要把所有问题塞进一个慢速 E2E。纯节点和路由应快速、确定；真实模型/数据库集成放在单独测试层。

    "new": {"running", "cancelled"},

    "completed": set(),
    "failed": set(),
    "rejected": set(),
    "cancelled": set(),

def assert_transition(previous: str, current: str) -> None:
    if current not in ALLOWED_TRANSITIONS.get(previous, set()):
        raise AssertionError(f"illegal transition: {previous} -> {current}")

路径指标：

6. 中断与恢复测试 ​

恢复测试不能只断言出现 __interrupt__。至少验证：

  1. Interrupt Payload 完整且不泄露；
  2. 相同 thread_id 恢复；
  3. 决定 Schema 与审批身份有效；
  4. 节点重放没有重复副作用；
  5. 拒绝/过期进入正确终态；
  6. 重复 Resume 有明确行为；
  7. 进程重启后持久 Checkpointer 可读；
  8. 旧 checkpoint 能迁移或粘到旧版本 Worker。

InMemorySaver 只能验证语义，不能验证重启。

8. 并发与 Reducer ​

并发测试关注正确性，不只关注变快：

  • 所有 fan-out 分支恰好执行一次；
  • Reducer 不丢数据、不重复；
  • 输出按稳定 Task ID 排序；
  • 一个分支失败时策略明确；
  • 并发上限生效；
  • 取消传播；
  • 共享资源没有竞态；
  • 写操作不被错误并行。

9. 多 Agent 轨迹与协作质量 ​

除了最终任务成功，评测：

指标含义
Routing AccuracyRouter 选择正确专家
Delegation Precision委派中有多少确实必要
Delegation Recall必要 Worker 是否都调用
Redundant Work Rate重复检索/工具/Agent 调用
Handoff Loop RateAgent 之间来回无进展
Context Leakage Rate不应共享的数据是否传递
Evidence Merge Accuracy汇总是否保留来源与冲突
Team Cost Delta相对单 Agent 的额外成本

用同一数据集做单 Agent 对照。多 Agent 只提高 1% 成功率却增加 5 倍成本，未必值得。

10. 完整离线 Interrupt/Resume 评测基线 ​

下面的程序构建审批图，暂停、恢复、执行幂等提交，再验证路径、状态和调用次数。

python
from __future__ import annotations

import hashlib
import operator
from dataclasses import dataclass
from typing import Annotated, Literal, TypedDict

from langgraph.checkpoint.memory import InMemorySaver
from langgraph.graph import END, START, StateGraph
from langgraph.types import Command, interrupt


class WorkflowState(TypedDict, total=False):
    request: str
    idempotency_key: str
    route: Literal["direct", "approval"]
    status: Literal["running", "completed", "rejected"]
    trace: Annotated[list[str], operator.add]
    receipt_id: str


class FakeIdempotentService:
    def __init__(self) -> None:
        self._receipts: dict[str, tuple[str, str]] = {}
        self.commit_count = 0

    def commit(self, key: str, fingerprint: str) -> str:
        if not key:
            raise ValueError("idempotency key is required")
        if not fingerprint:
            raise ValueError("operation fingerprint is required")
        existing = self._receipts.get(key)
        if existing is not None:
            saved_fingerprint, receipt = existing
            if saved_fingerprint != fingerprint:
                raise ValueError("idempotency key reused for another operation")
            return receipt
        self.commit_count += 1
        receipt = f"receipt-{self.commit_count}"
        self._receipts[key] = (fingerprint, receipt)
        return receipt


service = FakeIdempotentService()


def operation_fingerprint(state: WorkflowState) -> str:
    normalized = " ".join(state["request"].lower().split())
    payload = f"{state['route']}|{normalized}"
    return hashlib.sha256(payload.encode("utf-8")).hexdigest()


def classify(state: WorkflowState) -> WorkflowState:
    route: Literal["direct", "approval"] = (
        "approval"
        if "refund" in state["request"].lower()
        else "direct"
    )
    return {"route": route, "status": "running", "trace": ["classify"]}


def route_after_classify(
    state: WorkflowState,
) -> Literal["approve", "commit"]:
    return "approve" if state["route"] == "approval" else "commit"


def approve(state: WorkflowState) -> WorkflowState:
    raw = interrupt(
        {
            "kind": "refund_approval",
            "request": state["request"],
            "idempotency_key": state["idempotency_key"],
        }
    )
    if type(raw) is not bool:
        raise TypeError("approval decision must be bool")
    if not raw:
        return {"status": "rejected", "trace": ["approval:rejected"]}
    return {"status": "running", "trace": ["approval:approved"]}


def route_after_approval(
    state: WorkflowState,
) -> Literal["commit", "stop"]:
    return "commit" if state["status"] == "running" else "stop"


def commit(state: WorkflowState) -> WorkflowState:
    receipt = service.commit(
        state["idempotency_key"],
        operation_fingerprint(state),
    )
    return {
        "status": "completed",
        "receipt_id": receipt,
        "trace": ["commit"],
    }


def stop(_: WorkflowState) -> WorkflowState:
    return {"trace": ["stop"]}


builder = StateGraph(WorkflowState)
builder.add_node("classify", classify)
builder.add_node("approve", approve)
builder.add_node("commit", commit)
builder.add_node("stop", stop)
builder.add_edge(START, "classify")
builder.add_conditional_edges(
    "classify",
    route_after_classify,
    {"approve": "approve", "commit": "commit"},
)
builder.add_conditional_edges(
    "approve",
    route_after_approval,
    {"commit": "commit", "stop": "stop"},
)
builder.add_edge("commit", END)
builder.add_edge("stop", END)

graph = builder.compile(checkpointer=InMemorySaver())
config = {"configurable": {"thread_id": "eval-refund-1"}}

paused = graph.invoke(
    {
        "request": "Refund order A1024",
        "idempotency_key": "refund-A1024-v1",
        "trace": [],
    },
    config,
)
assert "__interrupt__" in paused
assert paused["trace"] == ["classify"]

completed = graph.invoke(Command(resume=True), config)
assert completed["status"] == "completed"
assert completed["trace"] == [
    "classify",
    "approval:approved",
    "commit",
]
assert completed["receipt_id"] == "receipt-1"
assert service.commit_count == 1

# The service itself remains idempotent if a node must retry.
same_fingerprint = operation_fingerprint(completed)
assert service.commit("refund-A1024-v1", same_fingerprint) == "receipt-1"
assert service.commit_count == 1

try:
    service.commit("refund-A1024-v1", "different-operation")
except ValueError as exc:
    assert "another operation" in str(exc)
else:
    raise AssertionError("same key with a different operation must conflict")


@dataclass(frozen=True)
class WorkflowCase:
    expected_status: str
    required_nodes: frozenset[str]
    forbidden_nodes: frozenset[str]
    max_steps: int


def evaluate(case: WorkflowCase, state: WorkflowState) -> dict[str, object]:
    trace = state.get("trace", [])
    visited = {
        item.split(":", maxsplit=1)[0]
        for item in trace
    }
    missing = case.required_nodes - visited
    forbidden = case.forbidden_nodes & visited
    return {
        "status_correct": state.get("status") == case.expected_status,
        "missing_nodes": sorted(missing),
        "forbidden_nodes": sorted(forbidden),
        "within_step_budget": len(trace) <= case.max_steps,
        "passed": (
            state.get("status") == case.expected_status
            and not missing
            and not forbidden
            and len(trace) <= case.max_steps
        ),
    }


evaluation = evaluate(
    WorkflowCase(
        expected_status="completed",
        required_nodes=frozenset({"classify", "approval", "commit"}),
        forbidden_nodes=frozenset({"submit_without_approval"}),
        max_steps=4,
    ),
    completed,
)
assert evaluation["passed"] is True

print(paused["trace"])
print(completed["trace"])
print(evaluation)

11. 并发图离线测试 ​

python
import operator
from typing import Annotated, TypedDict

from langgraph.graph import END, START, StateGraph


class ParallelState(TypedDict, total=False):
    results: Annotated[list[str], operator.add]
    ordered_results: list[str]
    trace: Annotated[list[str], operator.add]
    result_count: int


def worker_a(_: ParallelState) -> ParallelState:
    return {"results": ["a"], "trace": ["worker_a"]}


def worker_b(_: ParallelState) -> ParallelState:
    return {"results": ["b"], "trace": ["worker_b"]}


def join(state: ParallelState) -> ParallelState:
    ordered = sorted(state.get("results", []))
    return {
        "ordered_results": ordered,
        "result_count": len(ordered),
        "trace": ["join"],
    }


parallel = StateGraph(ParallelState)
parallel.add_node("worker_a", worker_a)
parallel.add_node("worker_b", worker_b)
parallel.add_node("join", join)
parallel.add_edge(START, "worker_a")
parallel.add_edge(START, "worker_b")
parallel.add_edge(["worker_a", "worker_b"], "join")
parallel.add_edge("join", END)
parallel_graph = parallel.compile()

result = parallel_graph.invoke({"results": [], "trace": []})
assert result["result_count"] == 2
assert result["ordered_results"] == ["a", "b"]
assert result["trace"][-1] == "join"

12. 故障注入 ​

必须主动制造：

  • Node 抛出临时/永久错误；
  • 工具超时、限流和格式错误；
  • checkpoint 写失败；
  • Worker 在副作用后崩溃；
  • Interrupt 永不恢复或过期；
  • 并行分支一个失败；
  • Reducer 收到重复 Task ID；
  • Router 反复选择相同节点；
  • 模型返回未知 handoff；
  • Store/数据库断连；
  • 旧 State 缺新字段。

每个故障都要有期望终态、是否重试、最大次数、补偿、告警和审计。测试不能无限等待；为图和依赖设置测试超时。

13. 死锁、活锁与循环 ​

死锁 ​

两个分支互相等待，或等待永远不会到达的人工/事件。检测等待时长、依赖图和租约。

活锁 ​

节点一直运行但没有 State 进展，例如两个 Agent 反复 handoff。比较状态指纹、Evidence ID 和 Todo 变化。

循环 ​

允许循环必须有：

max attempts
no-progress detector
wall-clock deadline
cost budget
terminal fallback

16. 发布、State 迁移与回滚 ​

工作流版本必须和 checkpoint 兼容策略绑定。

16.1 State Schema ​

为 State 保存 schema_version。新增可选字段可在读取时补默认；重命名、类型收紧和 Reducer 变化需要迁移函数与历史 fixture。

16.2 图拓扑 ​

删除/重命名节点可能让旧 checkpoint 无法恢复。策略：

  • 旧线程粘到旧 Graph Worker；
  • 部署迁移器转换 checkpoint；
  • 保留兼容节点直到旧线程排空；
  • 无法迁移时显式人工终止。

不要让运行中的 thread 在每次 Resume 随机落到不同图版本。

19. 常见错误 ​

只断言最终文本 ​

跳过审批或调用禁止工具也可能碰巧答对。断言 State、Trace、工具和终态。

用 InMemorySaver 宣称可恢复 ​

只证明进程内语义。持久后端必须做进程崩溃、连接池、备份和恢复测试。

在性能指标中包含人工等待 ​

会混淆计算慢和业务等待。分别报告 active latency 与 wall-clock completion。

并发测试依赖完成顺序 ​

会产生 flaky test。用稳定 Task ID 和确定性 reducer/排序。

新版本直接恢复所有旧线程 ​

拓扑或 State 已变化。使用版本粘性、迁移或兼容 Worker。

重试节点却没有领域幂等 ​

Checkpoint 不能撤销外部副作用。先设计幂等和未知结果查询。

20. 练习 ​

练习一：路径测试 ​

为订单、退款、无证据和非法输入建立 expected/forbidden nodes，并检查明确终态。

练习二：恢复 ​

测试批准、拒绝、非法决定、过期和重复 Resume。接入持久 Checkpointer 后杀掉进程再恢复。

练习三：故障注入 ​

在副作用成功后、checkpoint 前抛错。证明幂等键让恢复后 commit_count 仍为 1。

练习四：并发 ​

构建三分支图，随机延迟并重复运行 100 次；结果集合稳定、无重复、join 一次。

练习五：多 Agent 评测 ​

计算 Routing Accuracy、Delegation Precision、Handoff Loop 和 Team Cost Delta，与单 Agent 配对比较。

练习六：迁移 ​

保存旧 State fixtures，将字段重命名并增加节点。实现迁移与旧 Worker 粘性，演练回滚。

练习七：容量 ​

使用真实大小 State 压测 checkpoint、队列与 Worker，报告 P95、吞吐、连接和成本拐点。
