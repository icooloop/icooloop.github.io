服务化 ​

在 Notebook 里调用一次 Agent，只要得到回复就算成功；作为服务交付时，还必须处理身份、并发、断线、重复提交、取消、超时、错误契约和发布期间的请求。

本页继续使用售后 Agent，设计两类接口：

text
短请求：POST /v1/chat           -> 同步或流式回答
长任务：POST /v1/tasks          -> 202 + task_id
        GET  /v1/tasks/{id}     -> 查询状态
        GET  /v1/tasks/{id}/events -> SSE 事件
        DELETE /v1/tasks/{id}   -> 请求取消

核心目标不是“给 LangGraph 套一层 FastAPI”，而是让 API 契约与 Agent 执行生命周期解耦。

IMPORTANT

项目当前锁定环境包含 Python 3.12.13、Pydantic 2.13.4，没有安装 FastAPI。幂等、重试、健康检查等确定性代码已离线验证；FastAPI 完整示例是生产边界参考，必须在你锁定 FastAPI/ASGI Server 版本后重新安装、运行和压测，不能据此声称项目已验证 FastAPI。

1. 服务边界负责什么 ​

API 层应该负责：

  • 协议解析和 Pydantic 契约；
  • 认证结果转换为可信上下文；
  • 请求大小、速率和并发限制；
  • 幂等接收和任务所有权；
  • 将领域错误映射为稳定 HTTP 错误；
  • 流式事件、断线重连和取消；
  • liveness、readiness 和 graceful shutdown；
  • 生成 request/trace/task ID 并传播。

Agent/领域层负责：

  • Prompt、模型、工具、RAG 和图执行；
  • 业务状态转换；
  • 工具授权与审批；
  • 副作用幂等；
  • checkpoint 与恢复；
  • 领域错误和结果。

不要让 HTTP Request 对象渗透进每个 Node，也不要让 Node 自己返回 HTTP 状态码。这样同一工作流才能从 API、队列、CLI 和测试复用。

2. 同步、流式还是异步任务 ​

模式适用不适用
同步 JSON稳定且短于网关超时的调用深度研究、人工审批
SSE 流式单向 token/进度事件、浏览器易接入客户端持续双向控制
WebSocket高频双向语音、实时协作简单文本生成
异步任务 API长任务、排队、恢复、取消极低延迟单次查询

决策时看实际生命周期：

text
模型耗时 8 秒 + 工具 2 秒       -> 可同步，也可 SSE 改善体验
研究任务 5 分钟                -> 202 任务 API + SSE/轮询
等待人工审批数小时             -> 持久任务，不能占住 HTTP 连接
语音 Agent 持续双向音频         -> WebSocket/WebRTC 类通道
1

3
4

SSE 连接断开不等于取消任务。异步任务的执行权属于服务，客户端必须显式请求取消。

规则：

  • extra="forbid" 尽早发现客户端拼错字段；
  • 对 ID、文本、列表、字典都设上限；
  • 外部契约避免直接暴露 LangGraph State；

  • replayed=true 时 status 是任务当前状态；它不是首次接收时快照。

6. 幂等接收：重复请求不能产生两个任务 ​

移动网络重试、网关超时和用户双击都很常见。写接口要求客户端提供 Idempotency-Key：

text
第一次：key=abc, payload=P -> 创建 task-1, replayed=false
重试：  key=abc, payload=P -> 返回 task-1, replayed=true
冲突：  key=abc, payload=Q -> 409 IDEMPOTENCY_CONFLICT

import hashlib
import json
import uuid
from enum import StrEnum
from typing import Any

from pydantic import BaseModel


def payload_fingerprint(payload: dict[str, Any]) -> str:
    encoded = json.dumps(
        payload,
        sort_keys=True,
        separators=(",", ":"),
        ensure_ascii=True,
    ).encode("utf-8")
    return hashlib.sha256(encoded).hexdigest()


class TaskStatus(StrEnum):
    QUEUED = "queued"
    RUNNING = "running"
    SUCCEEDED = "succeeded"
    FAILED = "failed"


class TaskReceipt(BaseModel):
    task_id: str
    status: TaskStatus
    replayed: bool


class IdempotencyConflict(ValueError):
    pass


class IdempotencyRegistry:
    """教学用内存实现；生产必须使用事务存储。"""

    def __init__(self) -> None:
        self._entries: dict[
            tuple[str, str, str, str], tuple[str, str]
        ] = {}
        self._statuses: dict[str, TaskStatus] = {}

    def accept(
        self,
        *,
        tenant_id: str,
        actor_id: str,
        endpoint: str,
        key: str,
        payload: dict[str, Any],
    ) -> TaskReceipt:
        if not key:
            raise ValueError("idempotency key is required")

        fingerprint = payload_fingerprint(payload)
        scope = (tenant_id, actor_id, endpoint, key)
        existing = self._entries.get(scope)
        if existing is not None:
            previous_fingerprint, task_id = existing
            if previous_fingerprint != fingerprint:
                raise IdempotencyConflict(
                    "key was already used for another payload"
                )
            return TaskReceipt(
                task_id=task_id,
                status=self._statuses[task_id],
                replayed=True,
            )

        task_id = str(uuid.uuid4())
        self._entries[scope] = (fingerprint, task_id)
        self._statuses[task_id] = TaskStatus.QUEUED
        return TaskReceipt(
            task_id=task_id,
            status=TaskStatus.QUEUED,
            replayed=False,
        )

    def set_status(self, task_id: str, status: TaskStatus) -> None:
        self._statuses[task_id] = status

7. 一个完整的 FastAPI 边界参考 ​

下面示例实现认证占位、限流、幂等接收、查询、SSE、取消和健康检查。它故意使用内存存储以突出 HTTP 契约，不代表生产持久化。

WARNING

示例中的 dev-token 只是让代码可运行的本地占位，不是 JWT 验证。FastAPI 当前未安装在项目 .venv 中，因此本段未在项目环境实跑。实际项目必须锁定依赖，并替换身份、存储和 Worker。

from __future__ import annotations

import asyncio
import json
import time
import uuid
from collections import defaultdict, deque
from collections.abc import AsyncIterator
from dataclasses import dataclass, field
from enum import StrEnum
from typing import Annotated, Literal

from fastapi import (

from fastapi.exceptions import RequestValidationError

from pydantic import BaseModel, ConfigDict, Field
from starlette.exceptions import HTTPException as StarletteHTTPException


class TaskStatus(StrEnum):
    QUEUED = "queued"
    RUNNING = "running"
    CANCEL_REQUESTED = "cancel_requested"

class AcceptedResponse(BaseModel):

class ErrorBody(BaseModel):

class ApiError(HTTPException):
    def __init__(self, *, status_code: int, body: ErrorBody) -> None:
        super().__init__(
            status_code=status_code,
            detail=body.model_dump(mode="json"),
        )
        self.body = body


@dataclass(frozen=True)
class RequestContext:
    request_id: str
    actor_id: str
    tenant_id: str
    roles: frozenset[str]


@dataclass(frozen=True)
class TaskEvent:
    sequence: int
    event_type: str
    data: object


@dataclass
class TaskRecord:
    task_id: str
    tenant_id: str
    actor_id: str
    query: str
    status: TaskStatus = TaskStatus.QUEUED
    answer: str | None = None
    cancel_requested: bool = False
    events: list[TaskEvent] = field(default_factory=list)
    next_event_sequence: int = 1


app = FastAPI(title="After-sales Agent API", version="1.0.0")
tasks: dict[str, TaskRecord] = {}
idempotency: dict[tuple[str, str, str, str], tuple[str, str]] = {}
rate_windows: dict[str, deque[float]] = defaultdict(deque)


def problem(
    *,
    status_code: int,
    code: str,
    message: str,
    request_id: str,
    retryable: bool = False,
) -> ApiError:
    return ApiError(
        status_code=status_code,
        body=ErrorBody(
            code=code,
            message=message,
            request_id=request_id,
            retryable=retryable,
        ),
    )


def request_id_for(request: Request) -> str:
    existing = getattr(request.state, "request_id", None)
    if existing:
        return str(existing)
    request_id = request.headers.get("x-request-id") or str(uuid.uuid4())
    request.state.request_id = request_id
    return request_id


def error_response(status_code: int, body: ErrorBody) -> JSONResponse:
    return JSONResponse(
        status_code=status_code,
        content=body.model_dump(mode="json"),
        headers={"X-Request-ID": body.request_id},
    )


@app.exception_handler(ApiError)
async def api_error_handler(
    _request: Request, exc: ApiError
) -> JSONResponse:
    return error_response(exc.status_code, exc.body)


@app.exception_handler(RequestValidationError)
async def validation_error_handler(
    request: Request, exc: RequestValidationError
) -> JSONResponse:
    # 不把原始 input 回显到错误体，避免泄漏 Token、Prompt 或 PII。
    errors = [
        {
            "location": [str(part) for part in item["loc"]],
            "type": item["type"],
            "message": item["msg"],
        }
        for item in exc.errors()
    ]
    body = ErrorBody(
        code="VALIDATION_FAILED",
        message="request validation failed",
        request_id=request_id_for(request),
        retryable=False,
        details={"errors": errors},
    )
    return error_response(422, body)


@app.exception_handler(StarletteHTTPException)
async def framework_http_error_handler(
    request: Request, exc: StarletteHTTPException
) -> JSONResponse:
    codes = {404: "NOT_FOUND", 405: "METHOD_NOT_ALLOWED"}
    body = ErrorBody(
        code=codes.get(exc.status_code, "HTTP_ERROR"),
        message="request could not be processed",
        request_id=request_id_for(request),
        retryable=False,
    )
    return error_response(exc.status_code, body)


async def authenticate(
    request: Request,
    authorization: Annotated[str | None, Header()] = None,
) -> RequestContext:
    request_id = request_id_for(request)
    if authorization != "Bearer dev-token":
        raise problem(
            status_code=401,
            code="UNAUTHENTICATED",
            message="valid bearer token required",
            request_id=request_id,
        )
    return RequestContext(
        request_id=request_id,
        actor_id="user-1",
        tenant_id="acme",
        roles=frozenset(),
    )


def enforce_rate_limit(context: RequestContext) -> None:
    now = time.monotonic()
    key = f"{context.tenant_id}:{context.actor_id}"
    window = rate_windows[key]
    while window and window[0] <= now - 60:
        window.popleft()
    if len(window) >= 30:
        raise problem(
            status_code=429,
            code="RATE_LIMITED",
            message="request limit exceeded",
            request_id=context.request_id,
            retryable=True,
        )
    window.append(now)


SHARED_ACCESS_ROLES = {
    "read": "task:read:any",
    "cancel": "task:cancel:any",
}


def owned_task(
    task_id: str,
    context: RequestContext,
    *,
    access: Literal["read", "cancel"],
) -> TaskRecord:
    record = tasks.get(task_id)
    may_share = SHARED_ACCESS_ROLES[access] in context.roles
    # 同租户不等于同一用户。只有 owner 或显式共享角色可以访问。
    if (
        record is None
        or record.tenant_id != context.tenant_id
        or (record.actor_id != context.actor_id and not may_share)
    ):
        raise problem(
            status_code=404,
            code="TASK_NOT_FOUND",
            message="task does not exist",
            request_id=context.request_id,
        )
    return record


def emit(record: TaskRecord, event_type: str, data: object) -> None:
    record.events.append(
        TaskEvent(
            sequence=record.next_event_sequence,
            event_type=event_type,
            data=data,
        )
    )
    record.next_event_sequence += 1


def events_after(record: TaskRecord, sequence: int) -> list[TaskEvent]:
    # 数据库实现必须 WHERE sequence > :cursor ORDER BY sequence。
    return [
        event for event in record.events if event.sequence > sequence
    ]


async def run_task(task_id: str) -> None:
    record = tasks[task_id]
    record.status = TaskStatus.RUNNING
    emit(record, "status", {"status": record.status})
    try:
        for step in range(3):
            if record.cancel_requested:
                record.status = TaskStatus.CANCELED
                emit(record, "status", {"status": record.status})
                return
            await asyncio.sleep(0.1)
            emit(record, "progress", {"step": step + 1, "total": 3})

        record.answer = f"已处理：{record.query}"
        record.status = TaskStatus.SUCCEEDED
        emit(record, "final", {"answer": record.answer})
    except Exception:
        record.status = TaskStatus.FAILED
        emit(record, "error", {"code": "TASK_FAILED"})


@app.post(
    "/v1/tasks",
    response_model=AcceptedResponse,
    status_code=status.HTTP_202_ACCEPTED,
)
async def create_task(
    body: CreateTaskRequest,
    context: Annotated[RequestContext, Depends(authenticate)],
    idempotency_key: Annotated[str | None, Header()] = None,
) -> AcceptedResponse:
    enforce_rate_limit(context)
    if not idempotency_key:
        raise problem(
            status_code=400,
            code="IDEMPOTENCY_KEY_REQUIRED",
            message="Idempotency-Key header is required",
            request_id=context.request_id,
        )

    fingerprint = body.model_dump_json()
    scope = (
        context.tenant_id,
        context.actor_id,
        "POST /v1/tasks",
        idempotency_key,
    )
    previous = idempotency.get(scope)
    if previous is not None:
        previous_fingerprint, task_id = previous
        if previous_fingerprint != fingerprint:
            raise problem(
                status_code=409,
                code="IDEMPOTENCY_CONFLICT",
                message="key already used for another payload",
                request_id=context.request_id,
            )
        record = owned_task(task_id, context, access="read")
        return AcceptedResponse(
            task_id=task_id,
            status=record.status,
            replayed=True,
            status_url=f"/v1/tasks/{task_id}",
            events_url=f"/v1/tasks/{task_id}/events",
        )

    task_id = str(uuid.uuid4())
    record = TaskRecord(
        task_id=task_id,
        tenant_id=context.tenant_id,
        actor_id=context.actor_id,
        query=body.query,
    )
    tasks[task_id] = record
    idempotency[scope] = (fingerprint, task_id)
    asyncio.create_task(run_task(task_id))
    return AcceptedResponse(
        task_id=task_id,
        status=record.status,
        replayed=False,
        status_url=f"/v1/tasks/{task_id}",
        events_url=f"/v1/tasks/{task_id}/events",
    )


@app.get("/v1/tasks/{task_id}", response_model=TaskResponse)
async def get_task(
    task_id: str,
    context: Annotated[RequestContext, Depends(authenticate)],
) -> TaskResponse:
    record = owned_task(task_id, context, access="read")
    return TaskResponse(
        task_id=record.task_id,
        status=record.status,
        answer=record.answer,
    )


@app.delete("/v1/tasks/{task_id}", status_code=202)
async def cancel_task(
    task_id: str,
    context: Annotated[RequestContext, Depends(authenticate)],
) -> dict[str, str]:
    record = owned_task(task_id, context, access="cancel")
    if record.status in {
        TaskStatus.SUCCEEDED,
        TaskStatus.FAILED,
        TaskStatus.CANCELED,
    }:
        raise problem(
            status_code=409,
            code="TASK_TERMINAL",
            message="terminal task cannot be canceled",
            request_id=context.request_id,
        )
    record.cancel_requested = True
    record.status = TaskStatus.CANCEL_REQUESTED
    emit(record, "status", {"status": record.status})
    return {"task_id": task_id, "status": "cancel_requested"}


@app.get("/v1/tasks/{task_id}/events")
async def task_events(
    task_id: str,
    context: Annotated[RequestContext, Depends(authenticate)],
    last_event_id: Annotated[int | None, Header(ge=0)] = None,
) -> Response:
    record = owned_task(task_id, context, access="read")
    cursor = last_event_id if last_event_id is not None else 0
    first_available = (
        record.events[0].sequence
        if record.events
        else record.next_event_sequence
    )
    latest_sequence = record.next_event_sequence - 1
    if cursor > latest_sequence:
        raise problem(
            status_code=409,
            code="EVENT_CURSOR_AHEAD",
            message="Last-Event-ID is ahead of the event log",
            request_id=context.request_id,
        )
    if cursor < first_available - 1:
        raise problem(
            status_code=410,
            code="EVENT_CURSOR_EXPIRED",
            message="requested events are no longer retained",
            request_id=context.request_id,
        )

    terminal = record.status in {
        TaskStatus.SUCCEEDED,
        TaskStatus.FAILED,
        TaskStatus.CANCELED,
    }
    if terminal and cursor == latest_sequence:
        # 204 明确告诉 EventSource 停止重连；不能静默返回空 SSE 流。
        return Response(
            status_code=204,
            headers={"X-Task-Status": record.status.value},
        )

    async def stream() -> AsyncIterator[str]:
        current = cursor
        while True:
            for event in events_after(record, current):
                current = event.sequence
                yield (
                    f"id: {event.sequence}\n"
                    f"event: {event.event_type}\n"
                    f"data: {json.dumps(event.data, ensure_ascii=False)}\n\n"
                )
            if record.status in {
                TaskStatus.SUCCEEDED,
                TaskStatus.FAILED,
                TaskStatus.CANCELED,
            }:
                return
            yield ": heartbeat\n\n"
            await asyncio.sleep(1)

    return StreamingResponse(
        stream(),
        media_type="text/event-stream",
        headers={"Cache-Control": "no-cache"},
    )

8. SSE 事件契约 ​

不要把模型供应商的原始 chunk 直接作为公共协议。定义自己的事件：

一个合格 SSE 帧：

text
id: 42
event: message.delta
data: {"task_id":"t-1","delta":"退款政策为"}

关键设计：

  • id 单调递增并可持久化；
  • 客户端带 Last-Event-ID 恢复，服务重放未读事件；
  • Last-Event-ID 必须是 >= 0 的整数；超前游标返回 409 EVENT_CURSOR_AHEAD，早于保留窗口返回 410 EVENT_CURSOR_EXPIRED；
  • heartbeat 防止代理误判空闲；
  • 数据使用 JSON 编码，不能让换行破坏帧；
  • 终态事件只能出现一次；
  • 断线只关闭订阅，不自动取消任务；
  • 代理关闭缓冲，并设置适合的空闲超时。

可靠重放不能用 events[cursor] 把序号误当数组下标。事件可能清理、分区或从非 1 开始，必须按持久序号查询：

FROM task_events
WHERE tenant_id = :tenant_id
  AND task_id = :task_id
  AND sequence > :last_event_id
ORDER BY sequence ASC
LIMIT :page_size;

查询前还要读取任务的 first_available_sequence 与 latest_sequence，区分过期和超前。若任务已终止且客户端已经读完最终事件，返回 HTTP 204 并携带当前任务状态，明确让 EventSource 停止重连；不能建立一个立刻结束、没有任何帧的“空成功流”。Token 流可短暂存内存；需要可靠恢复的业务事件必须落库或事件存储。

9. 限流、并发和背压 ​

限流不只是每 IP 每分钟请求数：

维度防止
IP未认证洪泛
actor单用户滥用
tenant一个客户耗尽全局容量
endpoint昂贵入口失控
model/tool下游配额被打满
concurrent tasks长任务无限堆积
tokens/cost少量超大请求绕过计数

令牌桶适合平滑速率，并发信号量限制同时执行数，队列长度与等待时间用于背压。容量不足时应尽早返回 429 或 503 和 Retry-After，不要接受一个永远排不到的任务。

多实例限流需要 Redis 或网关原子实现；页面示例的进程内 deque 只讲语义。

13. 健康检查 ​

liveness ​

回答“进程是否活着”。只检查事件循环/进程，不调用模型、数据库或外网。失败时编排器可重启。

readiness ​

回答“是否应接收新流量”。短超时检查必要依赖，例如数据库连接、任务队列发布能力、配置是否加载。模型供应商短暂异常是否影响 readiness 要按降级策略决定。

startup ​

用于迁移、模型资源加载等慢启动，避免 liveness 过早重启进程。

项目中的确定性健康报告：

python
from pydantic import BaseModel, ConfigDict


class DependencyStatus(BaseModel):
    model_config = ConfigDict(extra="forbid", strict=True)

    name: str
    required: bool
    healthy: bool


class HealthReport(BaseModel):
    live: bool
    ready: bool
    degraded: bool
    failed_dependencies: list[str]


def health_report(
    dependencies: list[DependencyStatus],
) -> HealthReport:
    failed = [item.name for item in dependencies if not item.healthy]
    required_failed = any(
        item.required and not item.healthy
        for item in dependencies
    )
    return HealthReport(
        live=True,
        ready=not required_failed,
        degraded=bool(failed),
        failed_dependencies=failed,
    )

14. Graceful Shutdown ​

停止实例时：

  1. readiness 先变为 false，停止接收新流量；
  2. 等待短同步请求和 SSE 写出；
  3. 停止领取新任务；
  4. 当前 Worker 在安全点完成或释放租约；
  5. flush Trace/指标，但设置硬超时；
  6. 关闭连接池；
  7. 超过 termination grace period 才强制结束。

应用不能依赖进程内 background task 完成关键工作。部署滚动更新、自动扩缩容和崩溃都会终止它。

15. API 版本与兼容 ​

  • 路径或 media type 版本化，如 /v1/tasks；
  • 新增可选字段通常兼容，删除/改类型不兼容；
  • 枚举新增值也可能破坏严格客户端；
  • 保存契约 OpenAPI 快照并做差异检查；
  • 内部 graph/state 版本与公共 API 版本分开；
  • 旧任务由兼容 Worker 完成，不能强行用新图恢复所有 checkpoint；
  • 弃用要有指标、期限和迁移文档。

16.2 FastAPI 集成测试清单 ​

锁定并安装 FastAPI 后，用测试客户端/真实 ASGI Server 检查：

  • 缺失、过期、错误 audience 的 Token 返回 401；
  • 请求体不能覆盖 actor/tenant；
  • 其他租户查询同一 task ID 得到 404；
  • 同租户其他用户也得到 404，除非具有端点要求的显式共享角色；
  • 同 key 同 payload 返回同 task；同 key 异 payload 返回 409；
  • 幂等重放返回任务当前公共状态，而不是固定 queued；
  • 业务错误、框架 404 和默认 422 都符合顶层 ErrorBody；
  • SSE ID 单调，断线后能从游标重放且 final 一次；
  • 负游标返回 422，超前游标返回 409，过期游标返回 410，已读完的终态重连返回 204；
  • 断开 SSE 不取消任务；显式取消最终收敛；
  • 限流返回 Retry-After，多实例结果一致；
  • 依赖故障影响 readiness 而非 liveness；
  • shutdown 后不再领取任务，租约正确释放。

17. 常见错误 ​

在 API 进程里启动不可恢复后台任务 ​

asyncio.create_task()、FastAPI BackgroundTasks 适合短小非关键工作，不适合数分钟 Agent、资金动作或人工等待。

把流断开当取消 ​

用户切换网络会断线。执行与订阅必须解耦，取消使用持久 API。

返回 200 并在正文写 error ​

客户端、网关和告警无法正确处理。使用稳定 HTTP 状态与错误 code。

用随机重试解决所有失败 ​

写操作可能已经提交。先分类失败和幂等语义，再决定重试或查询状态。

/health 调一次真实模型 ​

昂贵、慢且容易把供应商抖动变成重启风暴。健康检查要短、稳定、有明确依赖语义。

把内部 State 当 API 模型 ​

会泄漏敏感数据并把客户端耦合到图拓扑。显式建立公共投影。

19. 练习 ​

练习一：契约 ​

为研究 Agent 设计创建、查询、事件、取消和审批 API。禁止外部请求传 tenant，限制 query 和 metadata 大小。

练习二：幂等 ​

把内存 registry 改为 PostgreSQL，证明两个并发请求只创建一个任务，同 key 异 payload 返回冲突。

练习三：可靠 SSE ​

持久化事件游标。模拟第 10 个事件后断线，从 Last-Event-ID: 10 恢复，断言无遗漏、无重复 final。

练习四：取消 ​

在检索后、模型前、工具前和副作用提交后请求取消，分别定义正确终态和补偿策略。

练习五：限流与背压 ​

实现 actor、tenant 和并发任务三层配额。压测到队列饱和，验证早拒绝、Retry-After 和公平性。

练习六：故障映射 ​

注入模型超时、工具 429、数据库不可用、未知提交和非法参数，断言 HTTP/code/retryable 一致且无敏感堆栈。

练习七：优雅停止 ​

滚动终止 API 和 Worker，验证新流量停止、在途请求收敛、任务不丢失、租约不过期重入。

  • [ ] 能区分断线、取消请求与最终取消；
  • [ ] 能按 IP、actor、tenant、工具、token 和并发做限流；
