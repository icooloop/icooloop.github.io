性能与成本 ​

Agent 优化最容易走偏的方式，是看到某次请求很慢，就删 Prompt、降 top_k、并行所有 Tool，再宣布“快了”。这种改动可能让平均延迟下降，却提高幻觉、漏掉证据、突破供应商限流，甚至把本应串行的写操作执行两次。

正确目标不是“越快越好”，而是：

text
在质量、安全和可靠性门槛不下降的前提下，
降低用户感知延迟、资源消耗和单位成功任务成本。
1
2

本章建立完整优化方法：

  1. 固定评测集、版本和负载模型；
  2. 用 Trace 分解延迟与成本；
  3. 找到关键路径，而不是优化占比很小的步骤；
  4. 每次只验证一个假设；
  5. 同时检查质量、安全、吞吐和失败率；
  6. 用门禁决定是否发布和回滚。

学完后，你应该能够：

  • 区分首 Token、活跃执行、人工等待与端到端完成时间；
  • 设计冷启动、稳态、并发、长尾和故障基准；
  • 优化模型、上下文、Tool Loop、RAG、Checkpoint 和序列化；
  • 正确使用异步、并行、Semaphore、Queue 与背压；
  • 设计包含租户和版本的安全缓存键；
  • 计算 Token、工具、检索、存储和基础设施成本；
  • 为每个任务设置步骤、Token、费用和时间预算；
  • 建立质量-性能-成本联合发布门禁。

IMPORTANT

本页锁定项目已安装的 Python、LangChain、LangGraph 与 LangSmith 版本。完整性能实验使用离线、确定性工作负载，不连接真实模型或计费系统；示例成本是教学费率，不能当作任何供应商报价。资料能力边界截至 2026-07-13，采用真实模型前必须用目标区域、账号、限流和价格重新压测。

1.1 首次响应时间 ​

1.2 活跃执行时间 ​

Worker 实际运行 Node、模型、工具、检索和 Checkpoint 的时间。性能优化主要针对这里。

1.3 等待时间 ​

3.4 不只看平均数 ​

平均数会隐藏长尾。至少输出 P50/P95/P99、最大值、错误率、吞吐和队列深度。小样本的 P99 没有统计意义，应同时给样本数和置信区间或多轮结果。

4. 优化顺序 ​

推荐顺序：

  1. 消除错误循环和重复调用；
  2. 删除不必要模型调用；
  3. 减少无效上下文和返回数据；
  4. 优化关键路径中的检索、Tool 和 Checkpoint；
  5. 并行独立只读工作；
  6. 加入正确缓存与批处理；
  7. 调整模型和基础设施；
  8. 最后才做微小的 Python 层优化。

如果 Agent 因 Router 错误多调用两次模型，优化 JSON 序列化不会解决主要成本。

5. 模型调用优化 ​

5.1 减少调用次数 ​

  • 确定性规则能完成的校验不要调用模型；
  • 相同信息不要由多个 Agent 重复总结；
  • Tool 结果足够时直接进入结构化终态；
  • 把无进展检测放进 State，阻止无限反思；
  • 用一个结构化输出同时返回分类和必要参数，但不要塞入无关任务。

5.2 减少输入 Token ​

  • 只传当前 Node 需要的 State；
  • 压缩历史并保留事实、决定和未完成事项；
  • RAG 先检索/重排，再装配上下文；
  • Tool Schema 按本轮 Allowlist 绑定；
  • Subagent 使用最小 Task Envelope；
  • 大产物存文件/对象存储，只传引用。

5.3 控制输出 ​

  • 使用明确 Schema；
  • 设合理最大输出；
  • 不要求模型重复输入全文；
  • 需要 JSON 时不要同时生成长篇解释；
  • 流式展示不代表可以无限输出。

5.4 模型路由 ​

小模型可做分类、提取和简单改写；复杂推理或最终高风险回答使用更强模型。路由必须用分层数据集验证，不是凭直觉按“难/简单”分类。

  • 对重复只读调用做请求级去重；
  • 结果过大时分页、投影字段或保存 Artifact；

  • 写 Tool 不随意并行，也不做语义缓存；
  • UNKNOWN_COMMIT 先查权威状态，不盲重试。

7. RAG 性能 ​

7.1 Ingestion ​

  • 批量 Embedding；
  • 内容哈希避免未变化文档重算；
  • 增量索引与版本化切换；
  • 文档解析、切分、Embedding 分阶段计时；
  • 后台构建，不阻塞在线查询。

7.2 Retrieval ​

  • 元数据过滤尽量下推；
  • top_k 由召回评测决定；
  • 混合检索只在能提高质量时采用；
  • Rerank 候选数设上限；
  • 并行 Query Rewrite 要有总预算；
  • 缓存键包含 Tenant、ACL、Embedding 和 Index Version。

7.3 Context Assembly ​

按 Evidence ID 去重，控制每来源配额，优先覆盖不同问题子项。仅按相似度把多个重复 Chunk 塞满窗口，会增加 Token 却不增加信息。

8. 并发、背压与限流 ​

8.1 异步适合 I/O ​

Python asyncio 适合同时等待模型、HTTP、数据库等 I/O。CPU 密集解析、OCR 或本地模型推理需要线程/进程或独立服务，不能靠 async 自动变快。

8.2 有界并发 ​

错误：

python
results = await asyncio.gather(*(call_model(item) for item in many_items))
1

这会一次创建大量请求和内存对象。使用 Semaphore、Worker Pool 或有界 Queue。

8.3 背压 ​

入口速度大于处理能力时，应：

  • 拒绝或排队，而不是无限创建 Task；
  • 返回 Retry-After 或任务状态；
  • 按租户配额公平调度；
  • 限制每个 Graph 的并行分支；
  • 设置 Queue 最大长度、租约和过期；
  • 监控饱和度而不是只扩容。

9.1 可缓存 ​

  • 不变文档的 Embedding；
  • 版本固定的只读检索；
  • 确定性解析；
  • 低风险、可验证的模型中间结果；
  • Tool Schema 和模型能力元数据。

9.2 不应直接缓存 ​

  • 写操作结果；
  • 一次性审批；
  • 带动态权限但 Key 没有 Scope 的结果；
  • 强时效数据；
  • 未验证的语义相似回答；
  • 包含 Secret/PII 且无加密隔离的数据。

缓存需要 TTL、主动失效、版本切换、容量淘汰、加密与命中质量监控。

10. State、Checkpoint 与序列化 ​

Checkpoint 变大通常来自：

  • 完整消息历史；
  • 重复文档全文；
  • 二进制或大 JSON；
  • 每轮追加无界 Trace；
  • 多 Agent 共享全部中间结果。

优化：

  • State 保存引用和必要摘要；
  • 大 Artifact 放对象存储；
  • 为历史设置窗口与压缩策略；
  • 避免在 Reducer 中重复旧值；
  • 监控每个 Checkpoint 字节数和读写 P95；
  • 清理已完成 Thread，并遵守保留策略。

12. 完整离线实验：预算、缓存与有界并发 ​

python
from __future__ import annotations

import asyncio
import copy
import hashlib
import json
from dataclasses import dataclass
from math import ceil
from typing import Any

from pydantic import BaseModel, ConfigDict, Field


class BudgetExceeded(RuntimeError):
    pass


class ExecutionBudget(BaseModel):
    model_config = ConfigDict(
        extra="forbid",
        strict=True,
        allow_inf_nan=False,
    )

    max_model_calls: int = Field(ge=1)
    max_input_tokens: int = Field(ge=1)
    max_output_tokens: int = Field(ge=1)
    max_cost_usd: float = Field(gt=0)


class Usage(BaseModel):
    model_config = ConfigDict(
        extra="forbid",
        strict=True,
        allow_inf_nan=False,
    )

    model_calls: int = Field(default=0, ge=0)
    input_tokens: int = Field(default=0, ge=0)
    output_tokens: int = Field(default=0, ge=0)
    cost_usd: float = Field(default=0.0, ge=0)


class BudgetTracker:
    def __init__(self, budget: ExecutionBudget) -> None:
        self.budget = budget
        self.usage = Usage()

    def reserve(
        self,
        *,
        input_tokens: int,
        output_tokens: int,
        cost_usd: float,
    ) -> None:
        # 重新构造并验证累计值；model_copy(update=...) 不会验证 update。
        candidate = Usage(
            model_calls=self.usage.model_calls + 1,
            input_tokens=self.usage.input_tokens + input_tokens,
            output_tokens=self.usage.output_tokens + output_tokens,
            cost_usd=self.usage.cost_usd + cost_usd,
        )
        if candidate.model_calls > self.budget.max_model_calls:
            raise BudgetExceeded("model_call_budget")
        if candidate.input_tokens > self.budget.max_input_tokens:
            raise BudgetExceeded("input_token_budget")
        if candidate.output_tokens > self.budget.max_output_tokens:
            raise BudgetExceeded("output_token_budget")
        if candidate.cost_usd > self.budget.max_cost_usd:
            raise BudgetExceeded("cost_budget")
        self.usage = candidate


class CacheIdentity(BaseModel):
    model_config = ConfigDict(extra="forbid", strict=True, frozen=True)

    tenant_id: str
    scope: str
    authorization_fingerprint: str
    acl_version: str
    operation: str
    model: str
    model_parameters: dict[str, Any]
    prompt_version: str
    tool_schema_version: str
    data_version: str
    output_schema_version: str
    locale: str
    normalized_input: str

    def digest(self) -> str:
        payload = json.dumps(
            self.model_dump(mode="json"),
            sort_keys=True,
            separators=(",", ":"),
            allow_nan=False,
        ).encode("utf-8")
        return hashlib.sha256(payload).hexdigest()


class SafeCache:
    def __init__(self) -> None:
        self._values: dict[str, dict[str, Any]] = {}

    def get(self, identity: CacheIdentity) -> dict[str, Any] | None:
        value = self._values.get(identity.digest())
        return None if value is None else copy.deepcopy(value)

    def put(self, identity: CacheIdentity, value: dict[str, Any]) -> None:
        self._values[identity.digest()] = copy.deepcopy(value)


@dataclass
class ConcurrencyProbe:
    active: int = 0
    maximum: int = 0

    def enter(self) -> None:
        self.active += 1
        self.maximum = max(self.maximum, self.active)

    def leave(self) -> None:
        self.active -= 1


async def scripted_model_call(
    item: str,
    *,
    probe: ConcurrencyProbe,
    tracker: BudgetTracker,
) -> dict[str, object]:
    # 在发出外部调用前按上限预留；取消时保留预留量是安全的保守策略。
    tracker.reserve(
        input_tokens=20,
        output_tokens=8,
        cost_usd=0.001,
    )
    probe.enter()
    try:
        await asyncio.sleep(0.002)
        return {"item": item, "answer": item.upper()}
    finally:
        probe.leave()


async def run_batch(
    items: list[str],
    *,
    max_parallel: int,
    tracker: BudgetTracker,
) -> tuple[list[dict[str, object]], ConcurrencyProbe]:
    if max_parallel < 1:
        raise ValueError("max_parallel must be positive")
    probe = ConcurrencyProbe()
    queue: asyncio.Queue[tuple[int, str] | None] = asyncio.Queue(
        maxsize=max_parallel * 2
    )
    results: list[dict[str, object] | None] = [None] * len(items)

    async def produce() -> None:
        for index, item in enumerate(items):
            await queue.put((index, item))
        for _ in range(max_parallel):
            await queue.put(None)

    async def work() -> None:
        while True:
            job = await queue.get()
            try:
                if job is None:
                    return
                index, item = job
                results[index] = await scripted_model_call(
                    item,
                    probe=probe,
                    tracker=tracker,
                )
            finally:
                queue.task_done()

    try:
        async with asyncio.TaskGroup() as group:
            group.create_task(produce())
            for _ in range(max_parallel):
                group.create_task(work())
    except* BudgetExceeded as error_group:
        # TaskGroup 会取消并收割 Producer/Worker，避免异常后继续外呼。
        raise error_group.exceptions[0]

    if any(result is None for result in results):
        raise RuntimeError("batch finished without all results")
    return [result for result in results if result is not None], probe


class RunSample(BaseModel):
    success: bool
    active_ms: int = Field(ge=0)
    first_token_ms: int = Field(ge=0)
    cost_usd: float = Field(ge=0)


def percentile(values: list[int], ratio: float) -> int:
    if not values:
        raise ValueError("values must not be empty")
    if not 0 < ratio <= 1:
        raise ValueError("ratio must be in (0, 1]")
    ordered = sorted(values)
    index = ceil(len(ordered) * ratio) - 1
    return ordered[index]


def performance_report(samples: list[RunSample]) -> dict[str, float | int]:
    if not samples:
        raise ValueError("samples must not be empty")
    successful = [sample for sample in samples if sample.success]
    return {
        "count": len(samples),
        "success_rate": len(successful) / len(samples),
        "p95_active_ms": percentile(
            [sample.active_ms for sample in samples],
            0.95,
        ),
        "p95_first_token_ms": percentile(
            [sample.first_token_ms for sample in samples],
            0.95,
        ),
        "cost_per_success": (
            sum(sample.cost_usd for sample in samples) / len(successful)
            if successful else float("inf")
        ),
    }


async def main() -> None:
    budget = ExecutionBudget(
        max_model_calls=10,
        max_input_tokens=300,
        max_output_tokens=100,
        max_cost_usd=0.02,
    )
    tracker = BudgetTracker(budget)
    results, probe = await run_batch(
        ["refund", "shipping", "warranty", "invoice"],
        max_parallel=2,
        tracker=tracker,
    )

    assert [item["answer"] for item in results] == [
        "REFUND",
        "SHIPPING",
        "WARRANTY",
        "INVOICE",
    ]
    assert probe.maximum == 2
    assert probe.active == 0
    assert tracker.usage.model_calls == 4

    cache = SafeCache()
    base = CacheIdentity(
        tenant_id="acme",
        scope="knowledge:read",
        authorization_fingerprint="authz:viewer:documents-17",
        acl_version="acl-v7",
        operation="retrieve",
        model="embedding-a",
        model_parameters={"dimensions": 1024},
        prompt_version="query-v2",
        tool_schema_version="retriever-v3",
        data_version="index-2026-07",
        output_schema_version="retrieval-result-v1",
        locale="zh-CN",
        normalized_input="refund review time",
    )
    cache.put(base, {"ids": ["refund-policy#review"]})
    cached = cache.get(base)
    assert cached == {"ids": ["refund-policy#review"]}
    assert cached is not None
    cached["ids"].append("forged")
    assert cache.get(base) == {"ids": ["refund-policy#review"]}
    other_tenant = base.model_copy(update={"tenant_id": "other"})
    assert cache.get(other_tenant) is None
    other_acl = base.model_copy(update={"acl_version": "acl-v8"})
    assert cache.get(other_acl) is None

    report = performance_report(
        [
            RunSample(success=True, active_ms=320, first_token_ms=90, cost_usd=0.02),
            RunSample(success=True, active_ms=410, first_token_ms=110, cost_usd=0.03),
            RunSample(success=False, active_ms=900, first_token_ms=300, cost_usd=0.04),
        ]
    )
    assert report["success_rate"] == 2 / 3
    assert report["cost_per_success"] == 0.045

    print({"max_parallel": probe.maximum, "usage": tracker.usage.model_dump()})
    print(report)


if __name__ == "__main__":
    asyncio.run(main())

15. 容量规划 ​

使用 Little's Law 做初步估算：

但 Agent 具有长尾、人工等待和多依赖，不能只用平均数。容量测试还要观察：

  • Worker CPU/内存；
  • Event Loop Lag；
  • HTTP/DB/Redis 连接池；
  • 模型供应商并发和 Token 限流；
  • Queue Depth 与最老任务年龄；
  • Checkpoint 写吞吐和大小；
  • Collector/日志吞吐；
  • 单租户热点和公平性。

16. 常见错误 ​

用单个请求比较性能 ​

网络、缓存和冷启动噪声太大。使用多轮、分位数和固定数据集。

只优化平均延迟 ​

少量超时可能被平均值隐藏。检查 P95/P99 和失败样本。

无界并发 ​

本地看似更快，线上触发限流、连接耗尽和重试风暴。必须有 Semaphore、Queue 和背压。

缓存不含租户与版本 ​

导致越权、陈旧和错误复用。Cache Identity 必须完整。

把流式当总耗时优化 ​

流式改善首事件，仍需测总活跃时间、Token 和断线恢复。

降低 top_k 却不测召回 ​

可能省下几十毫秒，却漏掉关键证据。RAG 参数必须通过检索与端到端评测。

只算模型账单 ​

忽略工具、存储、观测、失败重试和人工成本，无法做真实 TCO。
