JavaScript 标准库 API 总索引 ​

本页汇总 ECMAScript 标准内置对象、属性和方法，基线为 ECMAScript 2026。适合通过站内搜索或浏览器页内搜索快速定位 API。

这里不包含 DOM、fetch()、console、定时器、structuredClone() 等 Web API，也不包含 Node.js 全局对象。尚未进入 ECMAScript 标准的 TC39 提案不会作为稳定 API 收录。不同浏览器和运行时的实现进度可能不同，使用较新 API 前仍需检查兼容性。

阅读约定 ​

  • “静态”表示通过构造器或命名空间调用，例如 Array.from()。
  • “实例”表示通过具体值调用，例如 array.map()。
  • 所有原型共有的 constructor，以及从 Object.prototype 继承的成员不重复列出。
  • [Symbol.xxx] 表示以知名 Symbol 为键的协议成员。
  • “已弃用”成员仅用于维护旧代码，不应出现在新代码中。

全局函数 ​

  • 求值与数值：eval()、isFinite()、isNaN()、parseFloat()、parseInt()

优先使用 Number.isFinite() 和 Number.isNaN()，它们不会先执行隐式数值转换。eval() 会扩大安全、性能和静态分析风险，应避免用于普通业务逻辑。

  • 消费与判断：every()、find()、forEach()、includes()、reduce()、some()
  • 协议：[Symbol.iterator]()、[Symbol.dispose]()

AsyncIterator ​

  • 协议：[Symbol.asyncIterator]()、[Symbol.asyncDispose]()
  • AsyncIterator 是异步迭代器原型对象，不应假定所有运行时都将它直接暴露为可构造全局对象

Promise ​

  • 静态组合：Promise.all()、Promise.allSettled()、Promise.any()、Promise.race()
  • 静态创建：Promise.reject()、Promise.resolve()、Promise.try()、Promise.withResolvers()
  • 实例方法：catch()、finally()、then()

生成器与异步函数对象 ​

  • Generator 实例：next()、return()、throw()、[Symbol.iterator]()、[Symbol.dispose]()
  • AsyncGenerator 实例：next()、return()、throw()、[Symbol.asyncIterator]()、[Symbol.asyncDispose]()
  • 内部构造器：GeneratorFunction、AsyncGeneratorFunction、AsyncFunction
  • 这些内部构造器通常通过函数对象的 constructor 获得，不作为普通全局构造器使用

DisposableStack ​

  • 实例属性：disposed
  • 注册资源：adopt()、defer()、use()
  • 转移与释放：dispose()、move()、[Symbol.dispose]()

AsyncDisposableStack ​

  • 实例属性：disposed
  • 注册资源：adopt()、defer()、use()
  • 转移与释放：disposeAsync()、move()、[Symbol.asyncDispose]()

显式资源管理还包括语言级 using 和 await using 声明；它们是语法，不属于标准库 API。

反射与代理 ​

Reflect ​

  • 函数调用与构造：Reflect.apply()、Reflect.construct()
  • 属性操作：Reflect.defineProperty()、Reflect.deleteProperty()、Reflect.get()、Reflect.getOwnPropertyDescriptor()、Reflect.has()、Reflect.ownKeys()、Reflect.set()
  • 原型操作：Reflect.getPrototypeOf()、Reflect.setPrototypeOf()
  • 扩展性：Reflect.isExtensible()、Reflect.preventExtensions()

Proxy ​

  • 创建：new Proxy(target, handler)
  • 静态：Proxy.revocable()
  • Handler 陷阱：apply()、construct()、defineProperty()、deleteProperty()、get()、getOwnPropertyDescriptor()、getPrototypeOf()、has()、isExtensible()、ownKeys()、preventExtensions()、set()、setPrototypeOf()

Proxy 陷阱必须遵守目标对象的不变量，否则相关操作会抛出 TypeError。
